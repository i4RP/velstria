ユーザーが撮った MLBB の画面収録（iPhone の横画面 1108×512・30fps。公開リポジトリへ転載しない・コミットしない）。

| 記号 | ファイル | 中身 |
| --- | --- | --- |
| a | `ScreenRecording_10-15-2026_11-08-11_1.mp4`（19.7 秒、`%TEMP%\mlbb_ref`） | 訓練場の Lv15 のフランコ（スキルの絵・鎖鉤・赤い髭・「鉄鎖旋」の説明で確認。README の「要確認」は解消）。0〜3.1 秒 S1 の照準、3.17 秒 S1、3.93 秒 命中、4.40〜4.63 秒 引き寄せ、6.17 秒 S2、7.37 / 8.17 / 8.97 / 9.77 秒 通常攻撃の命中、9.97 秒 奥義、13.5〜16.6 秒 走り |

コマ n の時刻 = n / 30 秒（OpenCV の位置）。ヒーローの足元は画面の (556.7, 294.6)、縮尺 62.3 px / MLBB の 1 単位（Tigreal と同じ較正、kits/Franco.md）。

MLBB のフランコは**右手に鉄の塊（錘）、左手に鎖の先の三本爪の鉤**を持つ。通常攻撃・スキル2・奥義で振るのは右手の錘、スキル1 で飛ぶのは爪の鉤。
Velstria のゴルムは右手の鎖鉤（Prop_hookChain、鉤の頭が錘の代わり）1 本だけなので、錘の振りも鉤の投げも右手の鎖鉤で行う（左手は空の拳）。

## 比較の手順

1. `tools/motion/h034-mlbb-compare.json` に段ごとの行（MLBB の動画と秒、Velstria のクリップと秒、MLBB のコマでのヒーローの画面の向き）を書く。
2. `blender -b --factory-startup -P tools/blender/preview_h034_motion.py -- --shots tools/motion/h034-mlbb-compare.json --stage <段>` で
   Velstria のコマを `build/h034-motion/compare/<段>/` に描く（戦闘の見下ろし 45° と横から。実際の鎖鉤を持たせる）。
3. `py -3.12 tools/mlbb_video/motion_compare.py tools/motion/h034-mlbb-compare.json <段> --shots build/h034-motion/compare --cols 3` で
   MLBB の切り出しと並べた一覧 `build/h034-motion/compare/<段>.jpg` を作る（git 管理外。MLBB のコマを含む）。
4. Velstria のコマは Blender の Workbench（実行時と同じ骨の解き方・武器の置き方。光・材質・演出は無い）。最後は fx-capture の撮影
   （`fxcap-h034-…`、lockstep の静止画）で試合の画を確かめる。見た目の最終判断はユーザーとコミュニティ。

Windows の Blender 4.5.10（`%LOCALAPPDATA%\Programs\BlenderLTS`）で author / preview とも回る（Hero_H034.usdz は揺れ物の骨が無いので落ちない）。

## 合わせる基準（MLBB で読んだ値）

| 項目 | MLBB（a のコマ） | Velstria の目標 |
| --- | --- | --- |
| 構え（待機・走り） | 16.0〜16.5 秒（カメラへ走る）: 右腕を体の横へ張り出して肘を曲げ、拳は腹の高さで体の外。錘は拳から下がって膝の横。左腕は腰の横。胸を張った猫背、膝を外へ曲げた幅の広い足 | 同じ構え。鎖鉤は拳から下へ垂らし、鉤の頭が膝の高さ |
| 走りの歩調 | 同じ足が後ろへ蹴り出すコマが 8 コマごと（2.00 / 2.27 秒、13.60 / 13.87 秒）→ 1 周 8 コマ（0.267 秒、毎秒 7.5 歩）。±1 コマ（脚が腹に隠れて読みにくい） | 8 コマ / 周を等速で再生する速さ = 試合の移動速度 |
| 歩幅 | 2.73 / 秒 × 0.267 秒 = 0.73 単位 / 周（脚の長さ 約 0.5 の 1.5 倍。ティグラルの 1.21 / 0.8 と同じ比） | 移動速度が mapScale 1.35 倍（3.51 m / 秒）なので、歩調を合わせて歩幅を 1.35 倍（0.94 m / 周）。足滑り 0 |
| 通常攻撃の型 | 7.37 ①・8.17 ②・8.97 ③・9.77 ① 秒。間隔 0.80 秒。① 横なぎ（右 → 左）・② 返し（左上 → 右）・③ 叩き落とし（頭の上 → 前の地面）の 3 種の繰り返し | 同じ 3 種を同じ順に。命中は sim の windup（間隔 × 0.25 = 0.8 秒で 0.20 秒）。クリップの命中 0.20 秒を伸縮 |

### 段 4: 揺れ物（2026-11-05）

H027・H029 のマントと同じ作り。`tools/blender/finish_h034_mane.py` が、揺れ物の骨の無い元（`61d826ba` の Hero_H034.usdz）から作り直す。

- 骨: CapeL1〜3・CapeR1〜3（Spine2 の子の鎖。肩の後ろ 1.34 → 1.12 → 0.92 m、背の髪の面に沿って z 0.27 → 0.31）。65 → 71 骨。
  三角形 9,386・頂点 4,757・UV・テクスチャ・材質は変えていない（USDZ は 1.28 → 1.39 MB。H027 の +114 KB と同じ詰め直しの分）。
- 重み: 背の面（z > 0.2）・y 0.75〜1.42・肩幅の内の赤茶の面（r > 1.45 g。前の髭・腕の肌・革の鎧は外れる）、20 面より小さな島を外して隣へ 2 回広げた（1,051 面）。
  長髪は体の殻そのもの（Tripo の 1 枚の面で、髪の下に背中の面が無い）なので、マントのように体から離して大きく振らず、付け根（1.38 m）から 32 cm で
  移し切る・背から離れた面ほど強く・最大 65% だけ鎖へ移した（472 頂点、4 重み・合計の誤差 1.3e-7）。
- 実行時: `HeroSecondaryPose.heroes` に H034 を足した（Entity・タイマー・物理は増えない。画面外は更新しない）。
- 確かめ方: Blender 4.5 は骨を足した USD の取り込みで落ちるので、numpy の線形ブレンドの皮で鎖を回した（`build/h034-motion/mane-lbs.png`）。
  動く頂点は背の髪だけ（y 0.81〜1.25）。走りの姿勢（−0.33 / −0.10 / −0.10 rad）で髪の先が 15 cm 後ろへ流れる（ヒーロー空間）。止まる時の前への揺れ
  （+0.25 rad を掛けた最悪の場合）は髪が背へ 11 cm 入る。実行時の前への目標は減速の 0.1 rad 以下なので、実際はその半分以下。
  author / preview は骨を足す前のモデル（`build/h034-motion/Hero_H034_base.usdz`）を読む（書き出しのクリップは同じになることを確かめた）。

### 演出（FX_H034）の合わせ

## 体の大きさ（2026-11-05、測定中）

MLBB のフランコは画面の上で髪の先 → 靴底 93〜95 px（a 1.00 秒の立ち姿 219 → 314、16.23 秒の走り 211 → 306）= 画面の高さの **18.4%**。
地面の縮尺 62.3 px / 単位で 1.51 単位。Velstria は H034 の模型の高さ 1.70 × scale 1.36 = 2.31 m。H029 の実測（scale 1.0 = 1.70 m が出荷のカメラで
75 px）から見積もると 102 px（19.9%、MLBB の 1.08 倍）。fx-capture の実際の描画（`fxcap-h034-motion-walk-apptests-r0--H034@field`）で測って決める。

## 残り（一周目の時点）

- MLBB の左手の爪（S1 で飛ぶのは爪、② の命中で的へ伸びるのも爪）は Velstria の模型に無い。右手の鎖鉤で代わりにしている。
