# 追加ヒーロー（Mobile Legends 参照・各レーン 2 体）

参照ヒーロー 12 体（`SKILL_REWORK.md`）に続き、Mobile Legends から各レーン 2 体を抜粋して追加する。
名前・二つ名は VELSTRIA の世界観に合わせて作り直し、デザインの方向性（武器・シルエット・配色・技の見た目）は元のヒーローにほぼ合わせる。
作業量が多いため段階に分ける。

| レーン | ロール | 第 1 段階 | 第 2 段階 |
|---|---|---|---|
| ゴールド（carry） | Ranger | H025 月弦のルミナ（ミヤ） | H030 星砲のライナ（ライラ） |
| ミッド（mid） | Arcanist | H026 紫電のエウリア（エウドラ） | H031 氷嵐のオーリア（オーロラ） |
| EXP（top） | Duelist | H027 竜槍のジャルド（趙子龍） | H032 赤拳のディアス（ディロス） |
| ジャングル（jungle） | Assassin | H028 断空のザイル（セイバー） | H033 紅牙のヴァルド（アルカード） |
| ローム（support） | Support | H029 聖槌のボルグ（ティグリアル） | H034 鎖鉤のゴルム（フランコ） |

ローム 2 体は **Support ロール**にする（ポジション=ロームに自動で入る。ULT は味方回復型の型になる。個別の挙動はスキル挙動フェーズで直す）。

## 第 1 段階の仕様

名前の列は「表示名 / code_name」。数値は `master_runtime.json` が正（`tools/hero_additions.mjs` が追記する）。

### H025 月弦のルミナ / Lumina — Ranger（ゴールド）。参照: ミヤ
- 月神殿の森エルフの弓使い。長い銀白の髪、尖った耳、月の飾り、翠と白の外套。三日月の長弓（矢は月光）。
- 攻撃: 月光の矢。S1: 分裂する月矢（扇状に飛ぶ）、S2: 月影に身を隠すステップ（短距離ブリンク+次の矢強化）、
  ULT: 月の祝福（月光を纏い攻撃速度・射程が増す。ゲーム側は貫通する大矢の型）、パッシブ「月環の導き」。
- スキル名: パッシブ 月環の導き / ULT 月華の天弦（S1 =「Lumina式・一閃」、S2 =「星環シフト」は共通名）。
- 配色: 翠緑・白銀・淡い月光の黄。

### H026 紫電のエウリア / Euria — Arcanist（ミッド）。参照: エウドラ
- 雷を操る若い魔導士。紫黒のドレスと短い外套、紫の髪、周囲に小さな雷球が浮く。細身の杖。
- S1: 分岐する雷（直線に走る稲妻）、S2: 雷球（命中で麻痺=スタン）、ULT: 天雷（対象地点に雷が降り注ぐ範囲攻撃）、パッシブ「紫電の囁き」。
- スキル名: パッシブ 紫電の囁き / ULT 九天雷鳴。
- 配色: 紫・黒・電光の白と水色。

### H027 竜槍のジャルド / Jarld — Duelist（EXP）。参照: 趙子龍
- 竜の意匠の銀青の鎧をまとう長槍の戦士。茶髪の結い髪、赤い房飾り。長い竜槍。近接。
- S1: 槍の連突き、S2: 竜牙の踏み込み突き（突進+打ち上げ=ノックバック）、ULT: 昇竜（敵ヒーローへ飛び込み連撃+軽減）、パッシブ「竜鱗の構え」。
- スキル名: パッシブ 竜鱗の構え / ULT 昇竜天翔。
- 配色: 銀青・白・赤の差し色。

### H028 断空のザイル / Zail — Assassin（ジャングル）。参照: セイバー
- 未来的な剣士。黒に近い濃紺の軽装甲、光る visor 風の目元、淡い青の光刃の長剣（片手・両手の持ち替え）。近接。
- S1: 加速の突進斬り、S2: 光刃の薙ぎ払い（ノックバック）、ULT: 標的へ瞬間移動し三連斬り+打ち上げ（スタン）、パッシブ「空断の理」。
- スキル名: パッシブ 空断の理 / ULT 三連断空。
- 配色: 濃紺・シアン・白。

### H029 聖槌のボルグ / Borg — Support（ローム）。参照: ティグリアル
- 青と金の重装騎士。大きな兜（青い房）、肩当て、巨大な槌と円盾。近接・大柄（scale 大きめ）。
- S1: 槌で叩く衝撃波（スロー）、S2: 聖槌の踏み込み（突進+打ち上げ=スタン）、
  ULT: 崩落聖域（周囲を引き寄せ叩き伏せる。ゲーム側は味方回復+シールド型で敵はスタン）、パッシブ「聖鎚の誓い」。
- スキル名: パッシブ 聖鎚の誓い / ULT 崩落聖域。
- 配色: 青・金・白。

## 第 2 段階の仕様

### H030 星砲のライナ / Raina — Ranger（ゴールド）。参照: ライラ
- 桃みがかった金髪のツインテールの少女砲手。白と金の宇宙服風の戦闘服、赤い差し色。自分の背丈ほどの大きな星の砲。遠距離から撃ち抜く。
- S1: 連射する砲弾、S2: 反動で後ろへ下がる射撃（短距離ブリンク+次弾強化）、ULT: 星砕の大砲（長い貫通ビーム）、パッシブ「遠星の照準」。
- 配色: 桃・白・金。

### H031 氷嵐のオーリア / Oria — Arcanist（ミッド）。参照: オーロラ
- 背の高い氷の魔導士。淡い青白の長髪、氷の冠、白と氷青のドレス、氷の杖。周囲に氷の結晶が浮く。
- S1: 氷の弾（スロー）、S2: 凍結の波（拘束）、ULT: 絶界凍獄（対象地点を凍結する範囲スタン）、パッシブ「霜華の祝福」。
- 配色: 氷青・白・淡い紫。

### H032 赤拳のディアス / Dias — Duelist（EXP）。参照: ディロス
- 赤い気を纏う拳剣の戦士。黒髪、包帯を巻いた腕、赤黒の軽装甲。片腕に大きな刃付きの籠手（拳剣）。近接。
- S1: 拳剣の薙ぎ、S2: 跳躍して叩きつける踏み込み（スタン）、ULT: 煉獄連拳（連打して減速）、パッシブ「紅血の拳」。
- 配色: 赤・黒・鉄の灰。

### H033 紅牙のヴァルド / Vald — Assassin（ジャングル）。参照: アルカード
- 吸血鬼めいた大剣士。長い黒髪、蝙蝠の翼風のマント、深紅と黒の鎧。巨大な大剣（両手持ち、刃に赤い縁）。近接。
- S1: 大剣の叩き割り（スロー）、S2: 追い打ちの踏み込み、ULT: 血月断裂（標的へ飛びかかり斬り裂く。吸血）、パッシブ「吸血の渇き」。
- 配色: 深紅・黒・青白い肌。

### H034 鎖鉤のゴルム / Gorm — Support（ローム）。参照: フランコ
- 筋骨隆々の大男。頭巾か短い髪、鉄の肩当てと胸当て、腰に太い鎖。先に鉤のついた鎖を振り回す。近接・大柄（scale 大きめ）。
- S1: 鎖鉤を打ち出す（拘束=ルート）、S2: 殴りつける踏み込み（スロー）、ULT: 狩猟鎖獄（標的を鎖で縛り叩き伏せる。ゲーム側は味方回復+シールド型で敵はスタン）、パッシブ「鉄鎖の執念」。
- 配色: 鉄の灰・茶・錆びた赤。

## 触る場所（ヒーロー 1 体につき）

データ層（完了）: `tools/hero_additions.mjs` → `master_runtime.json`、`tools/gen_master_ja.py` / `gen_master_en.py` の表、
`master_ja.json` / `master_en.json`。

見た目の層（`AGENTS.md` が示す調査結果より）:

| 何を | どこ |
|---|---|
| 手続きモデルの設計図 | `App/Battle/Heroes/HeroBlueprints.swift` の `roster`（番号−1 の添字なので末尾に H025〜 の順で足す） |
| 武器・小物 | `HeroGear.swift`（必要なら新しい武器種を足す。足すなら `HeroBlueprint` の列挙も） |
| 通常攻撃・待機モーション | `App/Battle/Heroes/HeroMotionSets.swift` の `table[heroID]` と `App/Resources/Heroes/HeroMotionClips.json`（形式は `docs/HERO_MOTION.md`） |
| 通常攻撃の軌跡・命中・弾 | `App/Battle/Render/HeroFXProfiles.swift` の `specs[heroID]` |
| スキル演出（RealityKit） | `App/Battle/SkillFX/Heroes/FX_H0xx.swift` と `SkillFXCatalog.swift` への登録 |
| Effekseer | `tools/effekseer/heroes/h0xx.py` → `Effects/Effekseer/<heroID>_<stage>.efk`（`docs/EFFEKSEER.md`） |
| 立ち絵 | `tools/portraits/portraits.json`（生成は `portraits.py`）→ `Assets.xcassets/HeroPortraits|HeroSplash|HeroSplashMatte` |
| 件数を数えるテスト | 第 1 段階でヒーロー 24 → 29、スキル 96 → 116、コスメ 72 → 87、商品 114 → 134、演出 100 → 120。第 2 段階で 34 / 136 / 102 / 154 / 140 |
