# 年齢制限（Age Rating）の回答

ASC > App 情報 > 年齢制限 の質問票への回答。結果は **9+**（日本の App Store 表示も 9+）。
2025 年に改定された質問票（機能・成熟したテーマ・医療・性的表現・暴力・偶然性に基づく要素）に沿って記載する。
旧質問票の項目名も併記する。

## 回答

### 機能（Features / Capabilities）
| 質問 | 回答 | 理由 |
|---|---|---|
| ペアレンタルコントロール (Parental Controls) | いいえ | 年齢区分による月間購入上限はあるが、保護者向け管理機能ではない |
| 年齢確認 (Age Assurance) | いいえ | 自己申告の年齢区分のみ（購入上限の判定に使用） |
| 無制限の Web アクセス (Unrestricted Web Access) | いいえ | アプリ内ブラウザなし。外部リンクは固定のプライバシーポリシー/利用規約/サポートのみ |
| ユーザー生成コンテンツ (User-Generated Content) | いいえ | アプリ内の投稿・公開・検索・他の利用者への配信機能なし。リプレイだけは、利用者が共有シート／ファイル選択で `.vreplay` を書き出し・取り込める（送り先は利用者が選ぶ。ファイルにプレイヤー表示名を含む。アプリが自動で送信・公開することはない） |
| メッセージとチャット (Messaging and Chat) | いいえ | オンライン機能は公開版に無い（`FeatureFlags.online == false` かつ `FeatureFlags.lanMatch == false`） |
| 広告 (Advertising) | いいえ | 広告なし |

### 成熟したテーマ（Mature Themes）
| 質問 | 回答 |
|---|---|
| 冒涜的な言葉または下品なユーモア (Profanity or Crude Humor) | なし |
| ホラー/恐怖をテーマにしたもの (Horror/Fear Themes) | なし |
| アルコール、タバコ、ドラッグの使用または言及 | なし |

### 医療・ウェルネス
| 質問 | 回答 |
|---|---|
| 医療または治療に関する情報 | なし |
| 健康またはウェルネスに関するトピック | いいえ |

### 性的表現・ヌード
| 質問 | 回答 |
|---|---|
| 性的なコンテンツまたはヌード / 露骨な性的コンテンツ | なし |
| 挑発的なテーマ (Suggestive Themes) | なし |

### 暴力（Violence）
| 質問 | 回答 | 理由 |
|---|---|---|
| アニメまたはファンタジーの暴力 (Cartoon or Fantasy Violence) | **まれ/軽度 (Infrequent/Mild)** | 様式化されたファンタジーの戦闘。流血・欠損・遺体を表現しない演出方針（戦闘描画の実装で遵守し、release_checklist.md で確認）。倒されたヒーローは泉で復活する |
| リアルな暴力 (Realistic Violence) | なし | 実在の人物・動物・写実的な描写なし |
| 長時間にわたる生々しいまたはサディスティックでリアルな暴力 | なし | |
| 銃またはその他の武器 (Guns or Other Weapons) | なし | 剣・弓・杖はファンタジー表現の一部で、写実的な武器の描写・使用方法の提示はない |

### 偶然性に基づく要素（Chance-Based Activities）
| 質問 | 回答 | 理由 |
|---|---|---|
| 疑似ギャンブル (Simulated Gambling) | なし | カジノ・スロット等のミニゲームなし |
| コンテスト (Contests) | なし | |
| ギャンブル（実際のお金）| いいえ | |
| ルートボックス (Loot Boxes) | いいえ | 有料商品はすべて内容確定。ランダム付与の有料アイテムなし |

### App 内課金
- あり（ASC がアプリの App 内課金登録から自動で判定・表示する）。

## 結果と注意

- 年齢制限: **9+**。「Made for Kids（キッズカテゴリ）」には登録しない（年齢別課金上限は用意しているが、キッズカテゴリの要件は満たさない設計）。
- 以下を追加する場合は回答を見直す: 流血表現・写実的な武器、チャット/フレンド（Phase 2 のオンライン機能）、ランダム型有料アイテム、広告、Web ビュー。
  オンライン機能を有効化したら「メッセージとチャット」「ユーザー生成コンテンツ」が「はい」になり、通報・ブロック機能が必須になる（ガイドライン 1.2）。
- 韓国・ブラジル等の地域別レーティングは ASC が質問票から自動算出する。追加の書類が求められた地域は、対応できるまで配信対象から外す。
