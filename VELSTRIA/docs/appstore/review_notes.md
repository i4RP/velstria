# 審査メモ（App Review Notes）

ASC の「App Review に関する情報 > メモ」には英語版 [`metadata/review_information/notes.txt`](metadata/review_information/notes.txt)
をそのまま貼る（4,000 文字以内。`tools/validate_appstore_metadata.py` が検証）。以下は社内確認用の日本語訳と、各記載の根拠。

> 画面の導線（「ホーム > 対戦」など）は UI 実装の最終版と照合してから提出すること（release_checklist.md「審査メモの導線確認」）。
> 導線が変わった場合は notes.txt と本書を同時に更新する。

## 日本語訳

VELSTRIA - 星環の戦場 は完全オフラインの 5 対 5 MOBA です。味方も敵もすべてコンピュータ（AI）が操作します。
サーバー、アカウント・ログイン、チャット、マルチプレイ、ユーザー生成コンテンツはありません。
プレイに通信は不要で、通信は App 内課金（Apple の StoreKit）のみです。

**初回起動**
1. 利用規約とプライバシーポリシーに同意します。
2. 年齢区分を選びます。「20 歳以上」を選んでください。未成年の区分には月間購入上限（16 歳未満 月 5,000 円、16〜19 歳 月 10,000 円）があり、テスト購入がブロックされる場合があります。
3. 任意のプレイヤー名を入力します。チュートリアルはプレイしてもスキップしても構いません。

**各機能の場所**
- 対戦: ホーム > 対戦 > 通常戦（対 AI、イージー/ノーマル/ハード）またはランク戦（対 AI、BAN ありドラフト）> ヒーロー選択 > ロードアウト確定。1 試合 10〜18 分。
- 短時間で確認する場合: ホーム > 対戦 > 練習場。試合中メニューからいつでも退出できます。
- チュートリアル: 設定 > チュートリアル。
- 観戦（AI 同士）: ホーム > 対戦 > 観戦。自分の試合のリプレイ: プロフィール > リプレイ。
- ヒーロー・装備・ルーン・バトルスペル: ホーム画面のメニュー。
- 言語: 設定 > 言語 > English（既定では端末の言語に従います）。
- 端末内データの全削除: 設定 > プライバシー。
- 問い合わせ: 設定 > サポート。

**App 内課金**
- 消耗型アストラルジェム 6 種: `com.velstria.game.gem.60` / `.gem.300` / `.gem.980` / `.gem.1980` / `.gem.3280` / `.gem.6480`
- 非消耗型 1 種: `com.velstria.game.pass.premium`（スターパス プレミアム シーズン 1）

手順: ホーム > ストア > 通貨ストア > ジェムパックを選択 > 購入確定。検証済みトランザクションの完了と同時に有償ジェム残高が増えます。
ジェムはストアで見た目アイテムに使います。スターパス プレミアム: ホーム > スターパス > プレミアム解放。購入の復元はストアにあります。

有料アイテムは見た目のみで、戦闘能力は一切変わりません。ランダム型の有料アイテム（ルートボックス）はなく、
すべての商品は受け取る内容を明示しています。ヒーローはプレイで得られるスターライトコインで解放し、現金では販売しません。

**プライバシー**
データは一切収集しません。プロフィール、リプレイ、購入記録は端末内にのみ保存します。解析・広告・トラッキング SDK はなく、
App Tracking Transparency のダイアログも表示しません。iOS が提供するもの以外の暗号化は使用していません。

**対応機種**
iPhone のみ、横画面、iOS 18 以降。

## 記載の根拠

| 記載 | 根拠 |
|---|---|
| 完全オフライン・サーバーなし | DESIGN.md §0、`FeatureFlags.online == false`、ARCHITECTURE.md「ネットワーク通信なし」 |
| 年齢区分と月間上限 | DESIGN.md §12、`AgeBracket.monthlySpendLimitJPY`（13 歳未満・13〜15 歳 5,000 円、16〜19 歳 10,000 円） |
| 課金 7 商品 | DESIGN.md §13、`StoreKitService.gemProducts` / `premiumPassProductID`、[in_app_purchases.md](in_app_purchases.md) |
| 冪等付与・finish | DESIGN.md §13（`Transaction.id` で冪等化、検証済みのみ付与し `finish()`） |
| 見た目のみ・戦闘力なし | マスターの `competitive_power = 0`（全コスメ・全 SKU）、game_rules `monetization` |
| ヒーローはコインで解放 | マスター store の HeroUnlock は通貨 StarlightCoin |
| ルートボックスなし | ストア SKU は Cosmetic / HeroUnlock / Bundle（内容確定）のみ |
| データ削除 | `PersistenceService.deleteAll()`（設定 > プライバシー） |
