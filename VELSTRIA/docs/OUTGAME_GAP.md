**方針**
- 引き算が先。使われない部品・重複した入口・中身の無い画面・押しても何も起きないボタンを消す。足すのは MLBB にある物だけ。
- MLBB の名前・数字・配置をそのまま使う（Velstria 向けの換算をしない）。分からない所は「未確認」にし、日本語版のスクショで決める。
- BAN は入れない（10-12 のユーザー判断。ヒーロー 10 体）。チャットは定型文とエモートだけ（自由入力なし）。モードの解放条件は付けない。
- AI 戦でも「マッチング中 → 入場」を数秒見せる。ランキングは実在のアカウントだけ。今の架空の AI 50 人は「AI ラダー」として別枠。
- MLBB の画像・ロゴ・音・フォントは同梱しない（公開リポジトリ）。スクショは見本として見るだけでコミットしない。

**読み方**
- 「どうする」の【0】〜【3】は担当の段。【0】第0段（整理: モード選択の集約・ロビーの倍率・赤い点・古い文言・プライバシー・テスト）/【1】第1段（ロビー）/【2】第2段（戦闘準備: モード選択 → マッチング → ドラフト → ロード → リザルト）/【3】第3段（フレンド・メール・ランキング・名刺）。段の無い「残す」「保留」は今は何もしない。
- 「要スクショ」の #n は末尾の「ユーザーに頼むスクショ一覧」の番号。行番号（1-1 など）は一覧から引くため。
- 出典: PN = Fandom の Patch Notes（PN1.7.44・PN1.8.66・PN2.1.61・PN2.2.16）、LQ = Liquipedia の Patch（LQ2.1.30 = 2025-11-04、LQ2.1.47 = 2026-01-28）、Fandom ○○ = Fandom の各ページ、委員会 = 2026-10 の調査メモ（指示プロンプト製作委員会。出典ページ未特定）。
