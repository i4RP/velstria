# 一人称の視界比較（2026-10-27）

比較対象はユーザー提供の石畳・森林・夕空の参考画像。ローカル証跡は
`build/vision-quality/reference.jpg` と同ディレクトリの実機能スクリーンショット。
参考画像そのものは公開リポジトリには保存しない。

## 条件

iPhone 17 Pro シミュレータ、iOS 26.3.1、Debug arm64。
練習場、H003、seed 20261001、高画質、`-stageFull`、同じ開始位置。
更新前は `before.png`、第1段階は `iteration-1/battle.png`、第2段階は `iteration-2/battle.png`、第3段階は `iteration-3/battle.png`。
更新前は開始直後、第1・第2段階は65秒の計測後のため、ミニオンやHUD時計の差は景観評価に含めない。

シミュレータでは既存仕様により後処理が無効。実機のブルーム・FPS・発熱の比較ではない。
第1段階の計測は自動画質調整で noShadows まで下がったため、影の比較には使えない。
第2段階以降は `-visualReview` でフレーム時間による品質変動を止める（温度・低電力の制限は維持）。

## 比較から実装への反映

| 段階 | 画像で確認した差 | 反映した変更 |
| --- | --- | --- |
| 更新前 | 白い雲の輪郭が硬く、青空が強い。地平線の森が低く石畳は平坦 | 夕色〜青紫の空、雲の柔らかな透過境界、暖色の主光と青い補助光、初期視線を8度下向きに |
| 第1段階 | 空の色と地面の占有は近づいたが、森林と地面の質感はほぼ変わらない | 旧ステージ側の調整を試した後、現マップがインポート済みCanyonであることを確認 |
| 第2段階 | 旧ステージの樹木・舗装変更が現画面に反映されない | 該当変更を取り除き、Canyon専用の描画へ修正を集中 |
| 第3段階 | Canyonの無照明材質が奥行きを弱めている | 焼き込み色を残しつつ実際の光に反応する材質へ変更。高画質では既存チャンクの影を有効化 |
| 第3段階 | 低い樹冠と斜め方向の舗装のぼやけ | 元の樹木の高さ2.1m超を伸長。異方性8、正のmip biasを解除。三角形・チャンク数・ゲーム側の壁と通路データは不変 |

比較用の撮影は `tools/vision_review.sh UUID APP_PATH OUTPUT_DIRECTORY`。
Debug または SCREENSHOTS を有効にしてビルドしたアプリが必要。
毎回、実スクショ・perf-report・ソース差分・基準コミット・端末情報を保存する。

## 評価上の限界

参考画像とはマップ形状・撮影位置・HUD・機器が異なる。完全一致や客観的な総合点は主張しない。
参考画像の厚みのある石橋、局所的な炎の照り返し、密な針葉樹、背景の崖と建築は、色調整だけでは再現できない。
今回の舗装はフィルタリングと照明の改善で、石の立体形状を追加したものではない。

## 確認

- arm64 シミュレータの Debug ビルド成功。
- `StageTests/testTriangleBudget`、`testSolidPropsStayInsideWallsOrOutsideTheMap`、`testShaderLibraryIsUpToDate` の3件が成功。
- iOS / Simulator / macOS のステージシェーダー再生成成功。
- 初回の汎用シミュレータビルドは、既存 Effekseer ライブラリの x86_64 シンボル不足で失敗。arm64 を指定して解消。

## 第3段階の画像総評

- 空: 更新前の硬い白雲と強い青から、柔らかな雲と青紫・夕色へ。参考の雲の量や方向性までは一致しない。
- 光: Canyon本体が照明を受けるようになり、暗かった床と石壁、塔の面が読みやすくなった。
- 森: 既存樹冠の高さは反映。ただし参考の密な針葉樹林とは異なり、枝葉は疎ら。
- 石畳: 浅い角度の鮮明さを改善。参考の石橋の段差・厚み・目地の影は未達。
- HUD: 大きいミニマップとタッチ操作が画面を占める。参考の簡素なHUDとは設計が異なる。

この更新で参考画像と同等の品質に到達したとは評価しない。
次の優先項目は、樹冠の密度・石畳の立体形状・背景の崖・局所光。

Canyon本体の最終変更後は、`testCanyonStageFitsExistingBudgets`、
`testCanyonRejectsCorruptOrOverBudgetChunks`、`testShaderLibraryIsUpToDate` の3件が成功。
インポータの既存Pythonテスト8件も成功。
バンドルの地形は変更前後とも139,612三角形・242チャンク・3アトラス。
`CanyonLayout.json` と `CanyonStructures.json` に差分はない。

最終撮影は65秒完走、高画質・fullを維持、温度nominal、記録対象の戦闘中アセット生成0件。
撮影はDebugシミュレータであり、実機の性能改善を示す計測ではない。
