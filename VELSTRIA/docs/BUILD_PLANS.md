# バトルプラン（H025〜H034）

MLBB の元ヒーローを写した H025〜H034 に、MLBB と同じく 3 つずつの「バトルプラン」を持たせる。
出典は MLBB 日本語クライアントの「バトルプラン」画面のスクショ（2026-10-13。ヒーロー詳細 → ビルド → マイプラン）。
1 人につき 2 枚（上下にスクロールした画面）で 3 プランが写っていて、2 つ目のプランは両方に写っている。
スクショは公開リポジトリには入れない。

## 仕組み

| 何を | どこ |
|---|---|
| プランの中身（名前・英語名・タグ・装備 6 個・バトルスキル） | `ItemSystem.heroPlans`（`Packages/VelstriaCore/Sources/VelstriaCore/Systems/BuildPlans.swift`、画面の上から順） |
| 「有効」のプラン | `ItemSystem.defaultPlanIndex`。ヒーロー別の推奨ビルド `ItemSystem.heroBuilds` はこのプランの装備から作る |
| プランを選ぶ | ヒーロー詳細 → ビルド → バトルプラン の「使う」。`Profile.heroBuildPlans[heroID]`（既定のプランを選び直すと消える） |
| 試合へ渡す | `MatchFactory.*Match(humanBuildPlan:)`（オンラインは `OnlineLoadout.buildPlan` → `OnlineHumanSlot.buildPlan`）→ `PlayerSlot.buildPlan` → `HeroData.buildPlan` |
| 推奨ビルドに使う | `ItemSystem.recommendedBuild(for:)`: 人間が選んだプラン、無ければ「有効」のプラン。AI は常に「有効」のプラン |

- 戦闘中のおすすめ購入は、カスタムビルド（ビルド編集）を保存していればそちらが優先（これまでどおり）。
- 範囲外・不明の添字（古いデータ）は「有効」のプランとして扱う。`buildPlan` は任意の値なので、旧版の構成・リプレイは nil として読む。
- H027 / H030 / H032 の推奨ビルドも「有効」のプランになり、AI の買い物が変わるので `MatchConfig.currentSimVersion` を 16 に上げた。
- エンブレムはプランの `BuildPlan.emblem`（`docs/EMBLEMS.md`）。ボットは「有効」のプランのエンブレム、人間は一括設定のエンブレムが無ければ選んだプランのもの。
  プランごとの靴の祝福は `BuildPlan.blessing`（2026-10-21）。バッジの色の読みは ジャングルの赤 = 炎撃・青 = 氷刺、ロームの赤 = 激励（フランコの画面で確認）・紫 = 隠蔽。
  狩猟を持って靴を買うと選んだプランの祝福が付き、ボットのロームは「有効」のプランの祝福を付ける（`GearSystem.didChangeItems`）。
- `spellHint` は画面のバトルスキルの MLBB の名前で、表示用（シミュレーションのスペルは選ばない）。
  Velstria のスペルでいうと、フリッカー = 瞬歩（BS01）、浄化 = 浄化（BS02）、天罰 = 狩猟印（BS05）、処刑 = 処断（BS11）、
  激励 = 鼓舞（BS12）、石化 = 石化（BS13）、炎の弾 = 火炎弾（BS14）、復讐 = 報復（BS15）。

## 見分け方

装備・バトルスキル・エンブレムのタレントは、スクショから切り出したアイコンを MLBB Fandom の画像（装備は Velstria の ID 名で保存したもの）と
画素の差で照合し、上位の候補を並べた見比べ用のシートで目で確かめた。どの枠も 1 位と 2 位の差が大きく、迷ったものは無い。

- ブラッドクロウ（EQ111、Haas's Claws）は Fandom に画像が無いので、マイヤ「ヒット＆アウェイ」の 4 枠目（確認済み）を見本にした。
- 右下の「…」バッジ・靴の右上の祝福のバッジは照合から外した（バッジの下の装備として数える）。
- エンブレムのセットはエンブレム画面のタブのアイコンと照合した（Fandom のセットの画像は画面のアイコンと絵が違う）。天賦は日本語クライアントの名前（仮のものは `docs/EMBLEMS.md`）と MLBB の英語名。
  前回は名前が分からなかった「金の盾と上向きの矢印」は **武器マスター**（Weapon Master。Fandom の画像名は `Weapon Master (Talent).png`）。
- 画面どおりのため、同じ中身のプランもある: マイヤの 1 つ目と 3 つ目（装備・エンブレム・バトルスキルまで同じ）、
  エウドラの 2 つ目と 3 つ目（エンブレムだけ違う）、セイバーの 2 つ目と 3 つ目（バトルスキルだけ違う）。
  エウドラの 2・3 つ目には物理の装備の天空の刃（EQ115）が入っているが、画面どおりにしている。
