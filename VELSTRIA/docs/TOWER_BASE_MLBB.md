# 塔とベースを MLBB 2.2.16 に合わせる（2026-10-21）

指示プロンプト製作委員会A の調べ（2026-10-21、origin/main b34315e 時点）と、委員会のネット調べ（MLBB の塔、本サーバー 2.2.16）からの作業。
問題は「1 本目の塔が壊れると、2 本目・3 本目・ベースまで一気に崩れて、試合がすぐ終わる」。
方針は「MLBB の数値と規則をそのまま入れる。換算も丸めもしない」。資料に無い値は仮の値として下の「資料に無い値」に書いた。

日本語版の表記: アウタータワー / インナータワー / ベースタワー / ベース、エネルギーシールド、聖なる防御、精鋭兵（スーパーミニオン）/ 強化精鋭兵、チーム賞金。
コードでは外塔 = アウター、内塔 = インナー、基部塔 = ベースタワー、Core（Star Core）= ベース。

## 塔の攻撃（`TowerSystem.attackDamage`・`chooseTarget`）

- **確定ダメージ**（防御・被ダメ軽減を無視）。前は物理だった。ダメージは撃った時に決まる。
- 同じヒーローに続けて当てると、1 発ごとに攻撃の **+75%**（アウターなら +240）。**20 発目で止まる**（4880）。**最初の 1 発は −10%**（288）。
  **2 秒当てなければ戻る**。対象を替えても 2 秒以内に同じヒーローへ戻れば続く（ミニオンを撃っても途切れない）。前は +30% ずつ・上限 ×2.2・対象を替えると戻る。
- ミニオンへのダメージ（最大 HP の 近接 45%・遠隔 70%・攻城 14%）は MLBB の値が資料に無いので前のまま。
- 狙う順（MLBB の Fandom）:
  1. 今の対象がヒーローで射程内なら撃ち続ける（ほかの敵ヒーローが味方を攻撃しても替えない）。
  2. 射程内で、味方ヒーロー（射程より少し外 = +150 まで）を直近 2 秒に攻撃した敵ヒーロー。
  3. **召喚されたロード**（ミニオンの中で最優先。MLBB では味方ヒーロー扱い）。
  4. 今の対象（射程に最初に入った敵を撃ち続ける）。
  5. 最も近いミニオン > 最も近いヒーロー。
- **アウタータワーは、最初のミニオンが出てから 15 秒間（0:26 まで）攻撃せず、無敵**（`Balance.Tower.outerWakeTime`）。

## ベース・泉

- ベース: 攻撃 539、5 秒ごとに 165 回復（`TowerSystem.regenerate`）。
- 泉: 敵ヒーローに **0.2 秒ごとに 2000** の確定ダメージ（前は毎秒 1000）。泉は無敵。

## ヒーローの塔へのダメージ

- 通常攻撃は塔に **物攻 100% + 魔攻 100%**（1.8.08。`CombatSystem.releaseAttack`）。スキルは前から構造物に当たらない。
- 2.2.16 の「ヒーロー自身のスキルで強化した通常攻撃は塔に当たる。エンブレム・スペル・装備の強化は塔では出ない」は入れていない（強化攻撃の扱いの整理が要る。次の課題）。

## ミニオン（2026-10-10 に作って main に入っていなかった構成を移した）

- 初回 **0:11**、以後 30 秒ごと。側レーンは 近接・遠隔・攻城 を 1 体ずつ。中央の最初の 10 波は 近接 1 + 遠隔 3、以後は側と同じ。
  前は初回 0:20・1 レーン 近接 3 + 遠隔 3・3 波ごとに攻城・10:00 から近接 4（1 波で塔が 15〜26 発撃つ間、ヒーローが塔を削れた）。
- 速さは standard の地図で 中央 405・側 388（ミニマップの点で測った値）。12:00 から毎分 +30、上限 +120（× `Balance.mapScale`）。
  **canyon のレーンは standard の 0.72〜0.74 倍の長さ**なので、速さと出る位置（コアから 900・1 列 200）をレーンの長さの比で縮め、
  ウェーブが MLBB と同じ時刻（中央 0:25・側 0:33）にレーンの中点で出会うようにした（`SpawnSystem.minionLaneScale`）。
- Gold/EXP レーンの補正は、最初の 10 波の攻城ミニオンだけ（Gold +45%・EXP +35%）。遠隔の XP は 32 → 50（Lv4 の目安を保つ）。
- **精鋭兵**: 相手のベースタワーを壊したレーンにだけ、以後のウェーブが精鋭兵で出る。能力値は資料に無いので仮の値（HP・攻撃 ×1.6、防御 +30、半径 ×1.2）。
  ロードを倒した後の強化精鋭兵は、ロードの近くのミニオンの強化（ジャングル担当）と重なる。
- 時間の伸び: 委員会の調べでは「時間で強化されるミニオンは乱闘だけ」だったが、1.5.78 のパッチノートに「近接・遠隔ミニオンの HP の伸びを増やした」とあり、
  5v5 にも伸びがある。値が資料に無いので、出た時刻の HP・攻撃 ×(1 + 0.03 × 分) は外さずに残した。

## 復活（`RespawnSystem.respawnTime`）

- **3.2 + 2.1 × Lv + 試合時間（分、切り捨て）**、上限 **90 秒**（1.4.86 の式。最後に公開された式）。前は 4 + 2 × Lv、12:00 から ×1.25、上限 40 秒。
- 18:00 から大きく伸びる（Fandom の Match Details）。量は資料に無いので、18 分を越えた分は 1 分につき 2 秒にした（仮）。買い戻しは無い。
- 例: 5:00 の Lv3 = 14.5 秒、13:00 の Lv10 = 37.2 秒、20:00 の Lv15 = 56.7 秒、37:30 以降の Lv15 = 90 秒。

## 経済

- 塔を壊した時の Gold: チーム全員に **アウター 60・インナー 80・ベースタワー 100**。近くにいたヒーローは 50 を分け合う（1 人なら 110 / 130 / 150）。
  ラストヒットのボーナスは無い。前は 1 本 750（止めに 150 + 全員 120）。近くの範囲と分け方は資料に無いので、XP の分配と同じ 1400・等分。
- **チーム賞金**: Gold（獲得の合計）で **1500 以上**負けている側が、自分たちの平均より Gold の多い敵を倒すと、倒した側の全員に追加 Gold。
  発動の金差 1500 だけが公表値（2.2.16 で 2000 → 1500）。額の式は資料に無いので仮の式: （倒された敵の Gold − 倒した側の平均）× 25% を 5 人で等分。

## ロード（召喚されたロード = 倒されて味方として出撃した古環の巨像）

- 塔とベースは、ミニオンより先にロードを撃つ。ミニオンは敵のロードをヒーローと同じ順で狙う（MLBB: ロードは味方ヒーロー扱い）。
- ボット: ロードが自軍の塔に近づくと（射程 + 1500）、削られる前から守る（ヒーロー 2 人分の脅威）。守りでは敵のロードを先に削る。
- ロードの能力値と塔への突進（8〜18 分に塔の最大 HP の 30% の確定ダメージ）・出撃するレーンは、ジャングル・ローム担当（docs/JUNGLE_ROAM_MLBB.md）。

## ボット（押し方・守り方）

| 前 | 今 |
|---|---|
| 集団の押し込みは深い段のレーンを優先 | 浅い塔から（外・内を順に取る）。ベースタワー・ベースは人数で勝っている時だけ。2 人以上少ない時は押しに出ない |
| ベースが開いたら 1 人欠けただけで押し切る | ベースが開いただけでは押し切らない。ベースタワー・ベース・敵の泉の近くは、死んでいる敵だけを「戦線に居ない」と数える |
| 塔とベースの止めを戦闘より優先（ベース 9 秒・塔 5 秒で壊せるなら） | ベース 4 秒・塔 3 秒。近くの敵ヒーローの方が多い時・自分の HP 25% 以下では戦いを先にする |
| 集団期は外塔・内塔の防衛を捨てて取り合い | 守る塔より浅い塔との交換はしない（こちらの目標の方が削れている時だけ取り合い） |
| 泉の 1500 以内で見えた敵を「戦線に居ない」と数える（canyon では泉からベースまで約 1100） | 泉の中（800）で見えた敵だけ |
| ロード単独では守らない | ロードが近づくと守る・ロードを先に削る |
| 敵ヒーロー 2 人が攻めてくるのは塔が削られてから | 攻撃できるベースタワー・ベースに敵ヒーロー 2 人以上が近づいたら、削られる前から全員で守る |
| 押し切りでミニオンが来ない時、味方 3 人なら盾なしで叩く | 守りの敵ヒーローが見えていない時だけ |
| 塔に 3 発撃たれるまで粘る | 2 発で一度出る（塔の弾は確定ダメージで 288 → 560 → 800 と伸びる）。集団戦の見積もりの塔の火力は攻撃 × 2.5 |
