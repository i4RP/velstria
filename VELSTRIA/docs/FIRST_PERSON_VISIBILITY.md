# 一人称の自分の体と視界

通常プレイではキャラの目の位置から見回す。正面を見る間は、自分の胴・腕・装備による画面占有を10%未満に保ち、モデルの不透明度を50%にする。下を向いたときは胴・腕を確認できるよう表示範囲を広げる。

## 表示の仕組み

- `FirstPersonVisibility` は操作キャラのモデルだけに専用マテリアルを用意する。読み込み中に準備し、プレイ中はパラメータだけを更新する。
- `FirstPersonVisibility.metal` はスキニング後の画面位置で切り取り、正面では画面下の9%の帯だけを描く。帯の全幅を体や武器が覆っても占有は9%。姿勢・体格・攻撃の振り幅に依存しない。境界のぼかし0.3%も帯の内側に収める。
- 下向き20°までは同じ制限。下向き20〜60°で表示範囲を滑らかに広げ、60°以上で全体を許可する。正面へ戻すと9%の制限に戻る。
- `HeroVisual.modelRoot` の `OpacityComponent` は一人称へ入るフレームから最大0.5。草むら・ステルス・死亡のフェードはさらに薄くできる。
- 自分の頭部、頭上バー、足元リング、武器の軌跡、モデル付属の発光粒子・オーラは一人称で隠す。他キャラや別レイヤーのスキル範囲・攻撃判定は変更しない。
- 一人称から離れると元のマテリアルへ戻す。変換できない材質は制限中に隠し、検証ではエラーとして扱う。

## 検証の範囲

環境はiPhone 17シミュレータ、iOS 26.3.1、Debug、横画面。`FirstPersonVisibilityReview` は戦闘と同じモデル・モーション・レンズ・専用シェーダーを使い、1起動につき1体だけを表示する。

対象はマスター全34体。待機の1周期、歩行・走行、通常攻撃の各型、強化攻撃、S1・S2・奥義、専用モーションのある再使用・命中後の動作を、1/60秒刻みで進めて3Hzで撮影する。各キャラに下向き80°の画像も残す。

占有率は、同じシェーダーの白マスクを黒背景に描き、実際に表示された画面を `simctl io screenshot` で取得して数える。RGB最大値が8/255を超えるピクセルを丸ごと1と数え、半透明だから面積を半分にする計算はしない。`ARView.snapshot` は使用しない。

各サンプルで実際の不透明度コンポーネントが0.5、シェーダーの準備完了、未対応材質なしであることを確認する。空のスキル撮影、キャラの欠落・重複、不正な数値は合格にしない。下向きの白マスクが0.5%以下なら本体未表示として失敗にし、胴・腕の見え方は一覧画像でも確認する。

関連テストは重複を除いて82件が通過。正面の境界、下向きからの復帰、未対応材質の復元、モデルの不透明度などを含む。H025は実バトルUIで正面・下向き・見回しの画像を確認し、移動・攻撃・スキルを繰り返す65秒の自動操作も正常終了した。記録対象アセットのプレイ中生成は `ledger.live = {}`、`liveSamples = []`。

3Hzの撮影はモーション中の標本であり、全フレームの実撮影ではない。9%の上限は共通シェーダーの切り取り範囲で成立する。全34体の採取は隔離したモデル表示の検証であり、全スキル演出の読みやすさや実バトル全状況の検証結果ではない。下向き画像から全キャラの脚まで明瞭に見えるとは扱わない。

## 再現

リポジトリ直下から、専用シェーダーを含めたDebugシミュレータアプリをビルドして実行する。`--udid` は使うシミュレータを明示する。

```sh
uv run --with pillow --with numpy python VELSTRIA/tools/fps_visibility_review.py \
  --udid <UUID> --app <VELSTRIA.app> --hz 3 \
  --out VELSTRIA/build/fps-visibility
```

既定の対象はマスターの全定義、撮影頻度は3Hz。`--heroes H025` で対象を限定できる。中断後は `--resume` を付け、完了済みの撮影を再利用する。並列実行ではシミュレータと出力先を分ける。

```sh
uv run --with pillow --with numpy python VELSTRIA/tools/fps_visibility_review.py \
  --summarize-only \
  --inputs VELSTRIA/build/fps-visibility-a VELSTRIA/build/fps-visibility-b VELSTRIA/build/fps-visibility-c \
  --out VELSTRIA/build/fps-visibility-final
```

集計だけの実行はシミュレータにアクセスしない。全34体の一致を検証し、`summary.json`、`coverage.csv`、キャラ別の一覧画像、`roster-contact.png` を出す。元のマスク・サンプル目録は各採取フォルダに残し、集計フォルダからシンボリックリンクで参照する。

旧撮影形式の `masterRoster` は現行の選択対象一覧を意味する。集計時は元ファイルを書き換えず `currentPlayableRoster` として読み、全34体は `master_runtime.json` の全定義で検証する。新形式では `currentPlayableRoster` と `allHeroRoster` を明示する。

## 採取結果

2026-10-26、全34体・358シナリオ・2,399サンプルが合格。正面の最大占有率は **8.414%**（H020の通常攻撃・強化攻撃）で、全件10%未満だった。全サンプルで不透明度コンポーネント0.5を確認し、全34体の下向き画像で胴・腕を目視確認した。
