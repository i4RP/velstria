# スキルの範囲（判定）と演出の範囲を合わせる（2026-10-18〜）

ユーザーの指示（要約）: ゴルムなどで、スキルの範囲（判定）と演出の範囲が合っていない所がある。細かい所まで直す。
判定・数値（`Kit_H0xx.swift` の Tune・VelstriaCore の規則）は変えない。見た目の側を判定に合わせる。

1. 判定の表示（内部ビルドだけ・設定で切り替え）: sim が実際に判定した形を、判定の瞬間に地面へ細い線で 0.5 秒出す。
   演出チェックの録画・比較撮影の画にも写る。
2. 値を写さない: 演出（`FX_H0xx.swift`）に Kit の Tune の値を手で写さず、Kit から読む。照準の表示・判定・演出が同じ値を使う。
3. 縁の約束: 範囲を示す部品（輪の線・扇の縁・線の幅）は、判定の瞬間に見える縁が判定の縁と ±3% で一致する。広がる輪は判定の時刻に
   縁がちょうど判定の半径に来て、その外へは消えながら広がるだけ。板の大きさと見える縁の差は画像・形ごとの値（`FXEdge`）で補正する。
4. テスト: 全レシピで、判定の時刻の見える縁と判定の差を測る（`SkillFXRangeTests`）。
5. 食い違いの一覧（下の「食い違いの一覧」）。レーンごとに直して一覧と `SkillFXRangeTests.pending` から外す。

## 道具

### 判定の形の観測（Core: `Sim/HitShapeProbe.swift`）

- sim が当たりを調べた形（`HitShape`: 円・扇・線分（半幅つき）・多角形・単体の命中）を、その瞬間に受け口（`HitShapeProbe.sink`）へ渡す。
  形は判定そのものの寸法（対象の半径は含まない。どの判定も「対象の円が形に重なれば当たり」）。
- 出している所: ゾーンの発動と持続の毎回（`ZoneSystem.applyZone`。見た目だけのゾーンは出さない）、即時の範囲（`SkillArchetypes.hitArea`・
  `Kit.hitAreaEach`）、直線弾の毎 tick の区間（`ProjectileSystem`。通常攻撃は出さない）、経路ヒット突進の毎 tick の区間
  （`KitRuntime` の掃引）、対象指定の命中、キット独自の判定（H029 S1 の台形の帯・奥義の捕まえる円、H034 奥義の掴める距離と 1 撃ごと、
  H026 S2 の広がり・奥義の炸裂、H028 S1 の剣の輪の帯・剣撃の通り道、H031 奥義の霜の道）。
- 受け口が無い（既定）とき、判定の側の負担は `isActive` の読み取り 1 つ（形は autoclosure なので作らない）。SimState・SimEvent・
  乱数に触れないので、リプレイ・オンラインの同期は変わらない（`HitShapeProbeTests.testSinkDoesNotChangeTheMatch`: 受け口ありと
  なしの 150 秒の試合の状態・乱数・イベントが一致）。メインスレッドの sim だけ（裏のリプレイの事前計算は拾わない）。

### 判定の形の表示（App: `Battle/Render/HitShapeOverlay.swift`）

- 設定 > テスター用 >「判定の形を表示」（内部ビルド `DEBUG || TESTER_TOOLS` だけ。次の試合から）。比較撮影（`-fxCapture`）と
  起動引数 `-hitShapes` では常に出す（`-noHitShapes`、撮影のタグの名前に `clean` を含めると出さない。`apptests` を含めると撮影の前に
  `SkillFXRangeTests`・`SkillFXTests`・`FXCheckTests` も回し、成果物の `apptests.log` に残す）。
- 判定の瞬間から 0.5 秒（描画の時間）、地面（照準の少し上）に幅 6 cm の線。自分のチーム = 水色、相手 = 赤。弾・突進の毎 tick の区間は
  同じ弾・術者の線を 1 本につなぐ（カプセル）。持続するゾーンは最新の形に置き換える。シーク中の形は捨てる。
- 3D の場面の中に描くので、演出チェック（ReplayKit の録画）と比較撮影（`simctl io screenshot`）の画に写る。比較撮影は撮る間
  描画の時間を止めるので、0.5 秒の中の画には線が残る。
- 演出チェックで英雄にだけ撃てるスキル（H027 S1・H028 奥義・H034 奥義）は、撃つ直前に敵の英雄をヒーローの前 1.5 m に呼ぶ
  （以前は 4.2 m 先で、ゴルムの奥義の掴める距離 1.88 m に入らず撃てていなかった）。
- 線はチームごとの LowLevelMesh 1 つ（頂点だけ書き換え、上限 2048 本）。メッシュ・材質・エンティティは読み込み中に作り
  （`AssetLedger`）、試合中は作らない。

### 演出が読む値（`HeroKit.fxValues` → `FXSkillInfo`）

- Core: キットが `fxValues(slot:stage:)` で Tune の値を名前つき（`KitFXValue`: key = Tune の名前、単位 = 秒・距離・速さ・rad・数・比）で返す。
  App: `SkillFXCatalog.info(heroID:slot:stage:master:)` が `FXSkillInfo.kit` に入れ、レシピは `s.seconds("hookDelay")`・
  `s.meters("shockRadius")`・`s.speed("hookSpeed")`・`s.degrees(...)`・`s.count(...)`・`s.ratios(...)` で読む（m・秒・度に直す）。
- `FXSkillInfo` に判定の寸法も足した: `hitRadius`（照準の radius そのもの。下限 0.6 m の付いた `radius` とは別）、`halfAngle`（度）、
  `shape`、`stage`（再使用の段の照準・値）。
- 無い key を読むと 0 を返して `FXSkillInfo.misses` に残す。`SkillFXRangeTests.testEveryRecipeReadsOnlyExistingKitValues` が全レシピを
  組んで空であることを確かめる。

## 縁の決め方（`Battle/Render/SkillFX/FXEdge.swift`）

- 見える縁 = 画像の不透明度の輪郭（円い模様は円周の平均、横長の模様は行ごとの最大）が、その画像の最大の 1/3 以上になる最も外の位置。
  細い輪の外の淡いにじみ（0.25）は縁に入れない。値は `FXTextures.swift` の描き方から計算した表で、
  `SkillFXRangeTests.testRadialEdgeTableMatchesTheDrawnTextures` / `testLinearEdgeTableMatchesTheDrawnTextures` が実際の画像を
  標本化して 1.5 画素以内を確かめる（描き方を変えたら表も直す）。
- 円い模様（地面の板 disc）の縁の半径 / 板の一辺: ring 0.4575・ringDouble 0.455・shockwave 0.49・runeCircle 0.476・techCircle 0.468・
  clockFace 0.469・hexShield 0.48・bubble 0.44・ripple 0.48。例: 縁を半径 R に出す ring の板の一辺は R / 0.4575 = 2.19R
  （板の半分 = 縁、と思って 2R にすると縁は 0.915R）。
- 横長の模様の見える半幅 / 板の縦（ray・鎖のように板を 90° 回したときの横幅）: chain 0.1075・streak 0.08・arrow 0.11・slashLine 0.076・
  thread 0.135・bolt 0.2・soundWave 0.303・moon（三日月の上下の端）0.4。
- 形: 帯（band）の外縁 = size.x（内縁 0.8 倍）、弧（arc）の外縁 = size.x（横）・size.z（前）で見える開きは ±81°（beam の横の明るさが
  端の 5% で 1/3 に届かない）、円柱・漏斗・尖塔・半球・球は下端の半径（漏斗は 0.35 倍）、前を向いた板（wall）は横の端
  （円い模様なら縁の比 × 幅）。光（glow）・ひび（crack）・斬撃（slash）・粒子のコマ送りは範囲を示さない（比べない）。
- 時刻ごとの大きさ・不透明度・向きは `FXMesh.size(at:)` / `opacity(at:)` / `yawDegrees(at:)`（再生の `SkillFXPlayer.apply` と検査が同じ式）。

## 測り方（`Battle/Render/SkillFX/FXRangeAudit.swift`・`AppTests/SkillFXRangeTests.swift`）

1. スキルを sim で撃つ（`HitShapeScenario.run`: 練習場・Lv4・クールダウン無し、人形の南 4 m に北向き。演出チェック・比較撮影と同じ配置。
   英雄にだけ撃てるスキルは敵の英雄をヒーローの前 1.5 m に置く。再使用の段は演出チェックと同じ遅れで 2 回目）。判定の形・発動・
   ゾーン・弾・ダメージ・位置を時刻つきで集める。
2. 判定ごとに、それを出す演出の段と原点・前方・時刻を `SkillFXDirector` と同じ規則で決める: 扇・自身中心・味方全体 = 発動と同時の
   着弾（術者の足元）、対象指定のブリンク = 発動と同時の着弾（対象）、ゾーン = 予告（ゾーンの発生から）+ 着弾（最初の発動から）、
   直線弾 = 飛翔（弾に追従）、突進の掃引 = 発動（術者に追従）。発動・着弾の段の `durationFromCast` も同じく当てる。
3. その段の部品のうち範囲を示せるもの（上の「縁の決め方」で輪郭を持ち、地面に寝かせた・足元の部品。線の判定では体の高さの板・立てた板も）
   で、寿命の中の最大が判定の大きさの半分以上のもの（それより小さい輪は飾り）。円の判定は中心が判定の中心から 0.3 m（または 0.15R）以内、
   扇・帯の判定は中心が判定の中、線の判定は区間の近く（前後 1 m）の部品だけ。
4. 判定の時刻（部品が後から出るならその出始め。判定から 0.12 秒以内）の輪郭で、差を判定の大きさに対する比で測る。±3% を超えたら食い違い:
   - 円: 輪郭の全点の中心からの距離 − 半径（楕円・中心のずれも出る）。
   - 扇: 輪郭の最も遠い点 − 半径。扇の外（角度の外を含む）へのはみ出し。
   - 帯（H029 S1 の台形）: 部品が示している辺（縁から 15% 以内まで届く前・横の辺）までの差。帯の外へのはみ出し。後ろの辺は前の帯と
     重なるので比べない。
   - 線（弾・突進・線のゾーン）: 横の端（見える半幅 − 判定の半幅）。横のはみ出し。
5. 遅れ: 部品が判定より 1 tick（1/30 秒）を超えて遅れて出たら食い違い。sim の判定の時刻は tick に丸まる（例 0.27 秒の予約は 0.267〜0.3 秒）。
6. 広がる輪: 判定の時刻より後に判定の外（+3%）へ出てよいのは消え始めてから（`fadeOut` の後）。ease .out で縁 → 縁 × s に広がる部品は
   1.03 倍を越える寿命の比 1 − (1 − 0.03 / (s − 1))^(1/3) より前に消え始める（H029 の `edgeFade`）。判定の前（予告・広がる途中）に外へ
   見える縁が出るのもはみ出し。
7. 結果は「スキル 段#合図の番号 部品: 種類 差（説明 / 判定）」。`SkillFXRangeTests.testRangePartsMatchTheJudgmentEdges` が全ヒーローを
   調べ、H029・H034 は 0 件、ほかは `pending`（下の一覧）に載ったスキルだけを許す（新しい食い違いは失敗）。

計測環境: 判定の形・時刻は sim（決定論）なので、どの環境でも同じ。一覧は Windows の Swift 6.4（`swift run -c release` で
`FXRangeAudit` を `%TEMP%\fxrange` の調査用の包みに入れて回した。リポジトリには入れない）で作り、同じものを CI の iOS シミュレータの
`SkillFXRangeTests` が回す。画面の見え方（ブルーム・加算の白飛び・実機の FPS）はこの検査の外（実機で確かめる）。

## 食い違いの一覧（直し待ち。2026-10-18 の FXRangeAudit）

`SkillFXRangeTests.pending` に載せたスキル。レーンで演出を直したら、そのスキルを pending から外す（テストは新しい食い違いで落ち、
直ったスキルは「pending から外せる」と出す）。直し方の型:
- **縁 −15% より小さい**（広がる輪が判定の時刻にまだ小さい）: 判定の時刻に縁 = 判定の大きさで出し、外へは消えながら広げる
  （H029 の `edgeRing`: 板の一辺 = 半径 ÷ 縁の比、`fadeOut` は `edgeFade`）。
- **縁 ±数%**（予告の魔法陣など）: 板を縁の比で大きさを決める（runeCircle は 2R の板で縁 0.952R → 一辺 = R ÷ 0.476）。
- **遅れ**: 判定の時刻（ゾーンの発動・発動と同時の着弾は 0 秒）に出す。
- **外で消えない**: 判定の外へ広がる前に消え始める。
- **はみ出し**: 扇・帯・線の外へ出ない大きさに（扇に円い輪・横に広い三日月を使わない）。

判定の観測が無い（キット独自で共通の処理を通らない）単体の命中: H027 S1・奥義、H032 の一部の 1 撃。範囲を持たないので
比べるものは無い。範囲の部品が無いスキル（判定はあるが、地面に縁を持つ部品が無い・判定の半分より小さい）は一覧に出ない。
