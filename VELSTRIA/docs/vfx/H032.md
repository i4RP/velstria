# H032 ディアス（MLBB: Dyrroth）— スキル演出の対応

参考: 画面収録 vid6（39.7 秒）・vid7（18 秒）・vid12（20 秒）（2026-10-16、訓練場、1108×512・30fps）。コマ n の時刻 = (n − 1)/30 秒。
時刻は ±1 コマ（33 ms）。色は対象の箱の中の、明るく彩度の高い画素の中央値（色相で分けた。背景・体の画素も混ざる粗い値）。
形は目で見た読み取り（推定を含む）。判定・時刻は `docs/kits/Dyrroth.md` の測定どおりで、今回は変えていない。

## レイジ（体力バーの下の赤い線）で変わる見た目

MLBB はレイジ 50% 以上で撃ったスキル1・スキル2（アビス強化）の色が **紫 → 紅（マゼンタ寄りの赤）** に変わる。体（モデル）には
変化が無い（vid7 f50〜74 でレイジが 46 → 53% を越えても、拳まわりの赤い画素の数は 4〜27 で変わらない。HUD のバーとアイコンが赤くなるだけ）。

|---|---|---|
| スキル1 | 輪 3 つ・射程 4.72。鉤刃 #D74FFC / #C443F9、地が青紫に光る #5D2AE4 → #2C28AD | 輪 5 つ・射程 6.44。鉤刃 #F42E93 / #E52E7F、地は暗い #3B2939（藍 #2C439F が少し） |

| 致命の一撃 | 金の輪 #F4A758 + 紫の三日月 #B53AFB〜#DC5DF8 | 金の輪 #F4A758 + 紅の輪・三日月 #D73E4F / #ED5777 |
| 奥義 | レイジで変わらない | — |

Velstria での扱い（2026-10-17）: レシピはレイジを読めない（`SkillFXDirector` は `SkillCastEvent.count` を読まない）。
そこでパッシブのバッジ（`.stacks` = Int(レイジ / 50)）を `countedSlot` にし、バッジが減った = アビス強化を撃った瞬間に、
通常版だけの部品（`FXMesh.group` = 1）をまだ出ていない予定ごと消す（`spentGroups` → `SkillFXPlayer.cut`）。
消すことしかできない（強化版 ⊆ 通常版）ので、共通の部品はマゼンタ寄りにし、通常版にだけ青紫の光を重ねた:
- スキル1: 通常版だけ = 地の青紫の光（輪ごとに 1 枚、3 枚）。強化では消えて、マゼンタの鉤刃と暗い地だけになる。
- スキル2 の 1 回目: 通常版だけ = 青紫の彗星の尾と体の光（追従、0.04 秒から）。強化ではマゼンタ〜紅の筋と光の尾だけになる。
- 強化を放った瞬間（バッジ 1 → 0）: `passiveRelease` で拳の赤橙の光と体を包む紅の光（MLBB vid6 f621〜622・f282）。

## 変えられなかった・保留

- **強化のスキル1 の 4・5 つ目の輪**（4.2525 / 5.32m、0.86 / 1.06 秒）: レシピは強化かどうかを読めず、足せるのは「両方に出る部品」だけ
  （消すことしかできない）。4・5 つ目を置くと通常版にも出る。強化でそこに居る敵には被弾の閃きだけが出る。`SkillFXDirector` が
  `SkillCastEvent.count`（5）を読めば解ける（ほかのファイルなので触っていない）。
- **強化の紅そのもの**: 強化だけに足せないので、共通の部品をマゼンタ（#E63DAD・#DB3D80）にした。強化は「通常版の青紫が消えた」見た目で、
  MLBB の紅（#E52E7F・#E94478）より少し紫寄り。
- **致命の一撃の通常・強化**: 再使用ではレイジが減らない（1 回目で決まる）ので区別できない。紫の三日月 + マゼンタの 1 枚の共通の見た目。
- **レイジ 100 から撃った強化**（バッジ 2 → 1）: 通常版の部品は消える（cut は減ったときに働く）が、`passiveRelease` は 1 → 0 のときだけなので
  拳の赤橙の光が出ない。
- 通常版のスキル1 を撃っている間（0.7 秒以内）に命中のレイジで 50 を越えてすぐスキル2 を強化で撃つと、残りの輪の青紫の光も消える（稀）。

## 推定の項目

- 輪の浮きの高さ（中心が奥へ 0.4 ずれる → 0.25m に浮かせた）、鉤刃の数（MLBB は 3〜4 枚に見える → 3 枚）・回る向き。
- 奥義の前方の青紫の光の位置（案山子の足元に出た。的が居なくても出るかは動画に無い）。槍の長さ（2.4〜2.6m と見た）。
- vid7 f21〜25・vid6 f290〜295・f720〜726 の青白い炎は「255」と一緒に出るのでエンブレムの天賦と見て、写していない。
- 光る部品の明るさ・白飛び（シミュレータには後処理が無い。実機で確かめる）。炎・煙・斬撃のコマ送りは手続きの画像（MLBB の素材ではない）。
