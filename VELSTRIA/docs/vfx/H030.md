2026-10-21 に作り直した（第 3 段: Effekseer を段に重ねる・範囲の縁を判定に合わせる・全身のモーション）。音は変えていない
（効果音だけの MLBB の録画が届いてから。モーションで見つかった時刻の食い違いは末尾の表）。

- 参考: 画面収録 vid10（訓練場、Lv15・奥義 Lv3、1108×512・30fps・46 秒）。コマ n の時刻 = (n − 1)/30 秒、±1 コマ（33 ms）。
  リポジトリには入れない（ここは言葉と数値だけ）。指を離したコマと命中のコマは `docs/kits/Layla.md`（「動画で測った値」
  「スキルの溜めと星爆弾の照準」）のとおり。
- 色は Pillow で読んだ画素（発動前のコマとの差の上位 3%（`fxcolor.py`）、青い画素の中央値・明るい側・暗い側、球の中心からの輪ごとの
  中央値、ビームの断面）。形と大きさは目で見た読み取り（縮尺 55.1 px / 単位。宙のものは粗い）。
- 時刻・寸法は sim の判定（`Kit_H030.swift` の RainaTuning）。演出・モーションは `HeroKits.fxValues`（読むだけの口。2026-10-21 に
  Kit_H030 へ足した: s1Windup・s1Speed・s1Range・s1Width / s2Windup・s2Speed・s2Range・s2LockHalfAngle・ultRange・blastRadius・
  markDuration・markStun / ultWindup・ultBeamSpeed・ultWidth / farHitFlash）から読む（以前の手写しの 1.9・0.55・0.1 は消した）。
  判定・数値は変えていない。

**色について**: この動画のライラのエネルギーは**青と水色の白**（既定の見た目）。桃・紫は S2 の着く直前の一瞬（f984 #A64CC3）、
刻印の弾けの泡と電光、奥義の溜めの芯が金に変わる直前（f382 #F3D1DB）だけ。紫の光球・金の輪・星・魔法陣は MLBB に無いので使わない。

パレット: 芯 #F2FCFF / 主 #4A94E8（弾と球の青）/ 副 #A6F2FF（明るい縁の水色）/ 差し色 #FDDB82（奥義の溜めの金）/
暗色 #16214D（溜めの球の紺の殻）。ほかに 濃い青 #2660C3・藍 #4558B3・桃 #A64CC3・灰色の石 #5A6F88・刻印 #A5AEE2・照準線 #050814・
金に変わる芯の橙 #F3A86B。

砲口の位置（全身のモーションの撃つキーの星砲の先。術者の足元から x = 右・y = 上・z = 前、m。CI の目録のスキンの腕・脚の寸法で

## 残り・合わせられなかった点

- **シミュレータの画では S2 の破裂の青いガラスの球と奥義のビームが白っぽく淡い**（加算の青が明るい地面で白へ寄り、ブルームが無い）。

- **S1 の彗星の光が録画より太い**: 録画の彗星は幅 0.35〜0.45 m、範囲の約束で柔らかい光の見える横幅を当たりの幅 1.2 m にした
  （芯と体は録画の大きさ。光は縁の 1/3 の明るさで、ブルームで広がる録画の光と近い見え方の推定）。
- **ビームの細り方**: 録画は全長が一様に細る（太い 0.1 秒 → 0.17 秒で細る）。Velstria は貫通弾が 0.29 秒かけて進むので、外層は根元から
  先へ順に細る（先の区間は 0.35 秒太いまま）。白い芯は録画どおり先に一様に細る。
- **S2 の光球の弧**は 4.5 m 先の的で胸の高さに着く放物線 1 本。近い的では高い所で、遠い的では床の高さ（1.0 m）で着く（sim の弾は地面の上を
  追う追尾弾で、高さは演出だけ）。
- **S2 の爆発の足元の輪**は MLBB に無い（範囲の約束で足した。淡い水色・0.3 秒）。
- **S1 の命中の後の状態**: 加速・射程の延長（3 秒）の間ずっと出す演出は入れていない（HeroFXSet にスキルのバッジ・状態を見る口が無い）。
  MLBB でも体に常時の光は無く、歩き出しの速さの筋と電光（f505〜514）は命中の 0.8 秒後に出ていて、Velstria は命中の瞬間の術者の位置に置いた。

## モーション（打撃の時刻）

全身のモーション（App/Battle/Heroes/Motions/Motion_H030.swift。仕組みは docs/HERO_MOTION.md「全身のモーション」）。時刻は発動
（sim の SkillCastEvent = 指を離した tick）からの秒。撃つキーは sim の発射の時刻（`KitTimes` = `HeroKits.fxValues` = Kit_H030 の
RainaTuning。照準・判定・演出と同じ読み取り口）に置き、構え・反動・戻りの長さは MLBB の画面収録 vid10（30fps）から測った。
演出（FX_H030 の `at:`・砲口の位置）はこの表に合わせた。位置はヒーローの足元から（x = 右・y = 上・z = 前、m）の棒人形の値
