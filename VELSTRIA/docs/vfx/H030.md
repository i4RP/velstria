# H030 ライナ（MLBB: ライラ）— スキル演出の対応

参考: 画面収録 vid10（訓練場、Lv15・奥義 Lv3、1108×512・30fps・46 秒）。コマ n の時刻 = (n − 1)/30 秒、±1 コマ（33 ms）。
指を離したコマと命中のコマは `docs/kits/Layla.md`（「動画で測った値」「スキルの溜めと星爆弾の照準」）のとおり。
色は Pillow で読んだ画素（発動前のコマとの差の上位 3%（`fxcolor.py`）、青い画素の中央値・明るい側・暗い側、
球の中心からの輪ごとの中央値、ビームの断面）。形と大きさは目で見た読み取り（縮尺 55.1 px / 単位。宙のものは粗い）。
判定・sim の時刻（`Kit_H030.swift` の Tune）とモーションは変えていない。

**色について**: この動画のライラのエネルギーは**青と水色の白**（既定の見た目）。桃・紫は S2 の着く直前の一瞬（f984 #A64CC3）、
刻印の弾けの泡と電光、奥義の溜めの芯が金に変わる直前（f382 #F3D1DB）だけ。以前の紫の光球・金の輪・星・魔法陣は MLBB に無いので外した。

パレット（2026-10-17）: 芯 #F2FCFF / 主 #4A94E8（弾と球の青）/ 副 #A6F2FF（明るい縁の水色）/ 差し色 #FDDB82（奥義の溜めの金）/
暗色 #16214D（溜めの球の紺の殻）。ほかに 濃い青 #2660C3・藍 #4558B3・桃 #A64CC3・灰色の石 #5A6F88・刻印 #A5AEE2・照準線 #050814。

## 保留・変えられなかった点

- **S1 の命中の後の状態**: 加速・射程の延長（3 秒）の間ずっと出す演出は入れていない。HeroFXSet にスキルのバッジ・状態を見る口が無く
  （パッシブのタイマーだけ）、hit の合図は被弾者に追従するので、術者に付いて回る演出が書けない。MLBB でも体に常時の光は無く、
  歩き出しの速さの筋と電光（f505〜514）は命中の 0.8 秒後に出ていて、Velstria は命中の瞬間の術者の位置に置いた（ずれは推定）。
- **刻印の印**: MLBB は胸の淡い青紫の光の玉が弾けるまで残るが、Velstria の残りの表示は頭上の桃の印（`KitStatusVisuals.markColor` = 桃。
  担当外のファイル）。hit の光の玉は 0.7 秒だけ（刻印の弾けの被弾でも hit が再生されるので、長くすると弾けた後に残る）。
- **S1 の発射の閃光の時刻**: MLBB の砲口の閃光は弾の進みを中心に戻した時刻（sim の発射 0.1 秒）より 2〜3 コマ遅い（弾が 1.5m 先に居るころ）。
  sim の時刻に置いたまま。
- 着く直前の光球の紫の一瞬（f984）は出していない（travel は着弾の直前を知らない）。
- 奥義の溜めの球が一度縮む動き（f378 → f380）と、白桃の芯（f382）は省いた（青 → 金の 2 段）。
- 加算の白飛び・ブルームの見え方は実機で確かめる（シミュレータには後処理が無い）。

## 推定の項目

- S2 の尾の長さ（2〜2.5m）、爆発の球の見た目の半径（1.6 前後。宙の球を地面の縮尺で読んだ）、石の輪の半径（約 1.5）。
- 奥義のビームの細る速さ（30fps で 3〜4 コマ）、根元の殻の形（後ろへ丸い殻として見た）。
- S1 の彗星の長さ（約 1.7〜2m）と幅（約 0.35m）。射程の端で外れたときの S1・S2 の見た目（動画に無い）。
- dome の pitch −90（頂きが後ろ）、shockwave の板を暗い殻に使う見え方は CI の撮影で確かめる。
