# H029 ボルグ（MLBB: ティグラル）— スキル演出の対応

参考: 画面収録 vid1（2026-10-15、訓練場、Lv4、1108×512・30fps・15 秒）と vid2（2026-10-18、44 秒、同じ大きさ。S1・S2・再使用・奥義を
複数回）。コマ n の時刻 = (n − 1)/30 秒。時刻は ±1 コマ（33 ms）。大きさは CAMERA.md の縮尺（足元の近くで 62.3 px / m、奥は遠近で縮む）
で読んだ目安（±15%）。色は「発動前のコマとの差が大きい画素」の中央値と明るい側（`fxcolor.py`。粗い値）。形は目で見た読み取り（推定を含む）。
判定・時刻は `docs/kits/Tigreal.md` の測定どおりで、今回も変えていない（演出の打撃の時刻は sim の判定の時刻にそろえ、
時刻・寸法は `FXSkillInfo.kit`（Kit の値）から読む）。画面収録・コマはリポジトリに入れていない。

vid2 の発動（指を離した）時刻: S1 2.52 s（1 回目の爆ぜ f84 = 2.77 s の 0.25 秒前。2 回目 f94・3 回目 f104 は 10 コマおき）、
S2 の突進 16.40 s、再使用 18.07 s（「ノックアップ」の表示の 7 コマ前）、奥義 21.73 s（崩落 f682 = 22.70 s）。

素材（2026-10-18〜）: Blender で作った模型・コマ送り・模様（`tools/vfx_assets`）と、見せ場の粒の細部の Effekseer の効果
（`tools/effekseer/heroes/h029_kit.py` → `Effects/Effekseer/Kit/H029_*.efk`）。形の主役はメッシュ（模型・コマ送りのメッシュ。CI のシミュレータの
撮影に写る）、火花・残り火・岩片・煙は RealityKit の粒子（実機だけ）。爆炎・閃光・振りの軌跡は 3D の上に描く（`onTop`。MLBB の爆発は
英雄の体の上に描かれる）。
