## モーション（打撃の時刻）

全身のモーション（App/Battle/Heroes/Motions/Motion_H029.swift。仕組みは docs/HERO_MOTION.md「全身のモーション」）。時刻は発動
（sim の SkillCastEvent = 指を離した tick）からの秒。打撃のキーは sim の判定の時刻（`KitMotionTimings.Borg` = Kit_H029.Tune）に置き、
溜め・戻りの長さは MLBB の画面収録（30fps）から測った。演出（FX_H029 の `at:`）と音（tools/audio/skill_sounds.py）はこの表に合わせる。
MLBB のコマ: vid1（2026-10-15、15 秒）と rec2（2026-10-18 00:59、44 秒）。槌頭などの位置はヒーローの足元から（x = 右・y = 上・z = 前、m）の
推定（棒人形の寸法。スキンの寸法で ±0.2 m）。足首の目標・体の位置のずれは描画だけで、sim の位置は動かない（終わりで 0 に戻る）。
