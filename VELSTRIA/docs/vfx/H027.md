## 変えた点（まとめ）

- パレット: 金橙・青・赤 → 水色・青緑・深紅（MLBB の画面収録の色）。土煙は茶 → 灰色。
- スキル2: 金の筋と青い光の尾 → 対象へ伸びる光の槍・青緑の羽根の尾・深紅の帯。到着は白い閃きと青い弾け。青い鱗の盾が砕ける部品と赤いひびは外した。
- スキル1: 金の三日月 → 水色の三日月（大きく、太く現れて細る・流れる模様）。地面の金の筋・着地の地割れ・岩片を外し、灰色の土煙に。
- 奥義: 金と青の竜巻・炎の壁・噴き上がる炎 → 白い風 → 黄緑 → 青緑 → 水色の泡の色の移り。強化の間は体から立ちのぼる水色の筋。
- 突進の尾（スキル2）と強化の間の放出（奥義）は durationFromCast で sim の発動のイベントの長さ（突進の秒数・7.5 秒）に合わせた。
- 詠唱モーションは変えていない。

## 変えられなかった点・保留

- **通常攻撃（三連突きを含む）の色**: Effekseer の `.efk`（2026-10-12 に旧パレットの金で作り直したもの）と HeroFXProfiles の槍の帯は担当外のファイル。
  MLBB の通常攻撃も水色の弧・突き（f170・f193・f705）なので、スキルの水色と通常攻撃の金が食い違う。.efk を水色で作り直す必要がある（保留）。
- **三日月の「走る」動き**: MLBB は三日月が前から背後へ伸びていく（f471 → f474）。メッシュの回転は yaw（鉛直軸）→ pitch → roll の順で、
  立てた三日月の面の中で回す軸が無いので、弧に沿って流れる模様（flowing）と、太い → 細い の 3 枚の時間差で代えた。
- **スキル2 の物理防御ダウン（2 秒）の印**: MLBB の画面には出ない（情報パネルの「−30」だけ）ので、以前の赤いひび（1.9 秒）も外した。HUD の状態の表示に任せる。
- **奥義中の槍の光**: 穂先は攻撃のモーションで動くが、演出の位置は術者の足元からの固定の局所座標なので追えない。体から立ちのぼる筋だけにした。
- **被弾者が桃色に光る**（f137・f460）: MLBB の被弾の汎用の色と見て、スキルの演出には入れていない。
- 予算は余裕がある（上の表で足りた）。上限に当たった保留は無い。

## 推定の項目

- 光の槍の長さ 3.4m（f130 の 1 コマだけ）、三連突きの向きの差 12°、三連突きの帯の長さ 3.2m。
- 三日月の弦の向き（前後の軸から 40° ずらしたまま）・頂点の高さ ≈ 2.4m・流れる模様の向き（scroll の符号）。MLBB の三日月の 3D の形は 45° のカメラの 1 方向からしか見えない。
- 奥義の泡が球か地面の円か（f535 の楕円の縦横比 ≈ 0.6 なので地面の円 + ドームの両方を置いた）。f541〜f546 の細い楕円は通常攻撃の射程の円（HUD）と重なって区別できない。
- 光る部品の明るさ・白飛びの度合い（シミュレータには後処理が無い。実機で確かめる）。煙・渦のコマ送りの画像は手続きの画像（tools/vfx_sprites）で、MLBB の素材の写しではない。
