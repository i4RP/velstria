# 固定ワールド UI

2026-10-28。パーティ画面の参考画像に合わせ、バトル以外の表示を同じ青いワールドへ統合。
以前の Celestial ホーム、別画面の背景、起動ロゴ演出は使用しない。

- `RootView` は `PartyBackdrop` を一度だけ配置する。
- `WorldShellView` がルート・モード選択・初回設定・読み込み・試合結果を切り替える。
- `WorldShellFrame` が上部76pt、通常は左66%／右34%を管理。左側をタップするとフレンド欄が右へスライドして操作領域が広がり、右端48ptの余白をタップすると元の幅へ戻る。背景とフレンド欄の状態は保持し、視差効果を減らす設定では移動アニメーションを省く。
- ホームに戻るボタンは置かない。メニューは右上のグリッドアイコンから開き、子画面だけ戻るボタンを表示する。
- 起動直後は `HomeView` → `PartyLobbyView`。初回設定は「ゲーム開始」から同じ枠内に表示し、同意・年齢設定は省略しない。
- `ScreenScaffold` は `isWorldShellEmbedded` のとき中身だけを描画する。新規画面で背景や独立した全画面ヘッダーを追加しない。
- カードは `.worldShellCard()`、詳細・購入・報酬は `.worldPanel()`、閉じる操作は `worldPanelDismiss` を使用する。パネルはボタンではなく画面のルートに付ける。
- 課金・共有などOSが管理する画面はOSの表示を使う。
- 通常バトルとマジックチェスの戦闘再生だけが全画面。読み込み、結果、チェスの購入・精算はワールド内。
- 複雑なドラフト・スコア表は `WorldPanelViewport` で固定枠内に収める。

確認: iPhone 17 Pro Max / iOS 26.3 シミュレータ、Debug ビルド。
`WorldShellUITests` で初回起動、初回設定、ショップ・ヒーロー・イベント・設定・モード選択への遷移と共通欄の存在を確認する。
これは実機性能の測定ではない。オンライン対戦や購入の実取引はこの確認の対象外。
