# 戦闘UI・ミニマップ更新

ユーザー提供の ui2.jpg を基準に、2026-10-11 に戦闘HUDの配置・占有率・形状・透明度・文字階層を改修。RealityKitの戦場とSwiftUIのHUDを維持し、HUDModelの15Hzスナップショットと既存入力コマンドへ接続している。

## 表示と操作

- ミニマップは実際の`SimContext.map`から河川・通路・壁・草むら・泉を描く。通常表示は画面高さに合わせた小型表示。地形、マーカー、タッチ位置に共通の投影を使用する。
- 白いカメラ枠はレンダラーのカメラ姿勢と画面比率から求めた地面の四角形。ズーム、追従の平滑化、端の制限、振動を反映し、地図の境界と交差する辺をクリップする。観戦一時停止中も更新する。
- ヒーローは既存ポートレート、チーム色、円/ひし形で識別。自分と追従対象には白いリングと方向矢印を付ける。視界外の敵は最後の目撃位置に点線の残像を最大3秒表示する。
- 塔/コアのHPリング、破壊済み拠点、視界の霧、中立モンスターの種別を表示。通常キャンプの視界外での撃破は更新せず、観測できた再出現予定のみタイマーにする。ボスの予定は共有する。
- ミニマップ隅の小型拡大アイコンで全体マップを開く。大型の帯は廃止。ドラッグでカメラを移動し、通常プレイでは指を離すと自分へ戻る。観戦ではその地点に留まる。マップを開くと移動・攻撃・照準を解除し、閉じると操作を再開できる。試合は進行し続ける。
- 左利き配置ではマップと上部操作も反転し、攻撃群との重なりを防ぐ。マップの拡大ボタンは44ptのタッチ領域を持ち、移動入力領域から除外する。
- 試合時間・スコア・味方・戦績は上端へ小さく集約。右端は既存シグナルのみ。端末時刻を表示しない。
- 下中央のヒーローカードを廃止。名前・レベル・HP/リソースの頭上表示は既存のワールド追従を利用。装備6枠・売却・詳細HP/リソース数値・XP・状態・パッシブはショップに集約。所持金とショップ入口は右上、小型クイック購入はその左下。現行コードの通貨Goldを維持する。
- 攻撃を最大のシアン多角形、その左から上へ全3スキルを扇状に配置。対象指定は小型化。帰還と既存2スペルは下中央、所持中の装備／祝福アクティブはその上。絵柄は既存シンボル／所持素材を使用し、外部ゲームの素材を追加しない。
- 背景と線だけを薄くし、文字の可読性を維持。クールダウンの放射状マスク、秒数、未解放、リソース不足、習得＋、照準・キャンセル、長押し説明は従来モデルに接続。
- 画面高さに共通倍率を合わせ、端とSafe Areaへ固定。16:9では補助列を左へ寄せ、見た目が小さい操作も44pt以上の判定を維持。入力と描画の中心を共有する。
- DEBUGの統計は明示的な `-hud-debug-stats` 指定時だけ表示。UI撮影引数 `-hudCapture` はテスト専用FFボタンを隠す。泉／コアの水色の紋章は地形装飾なので維持する。

## MLBB 風の配置（2026-10-11）

Mobile Legends: Bang Bang の画面を参考に、操作中の HUD の見た目と配置を寄せた（観戦の配置は従来どおり）。

- 右上: K/D/A・CS をタップでスコアボード、画面の端に金色のゴールドの札（タップでショップ。死亡中は脈動）。独立したスコアボードのボタンは廃止。
- 下端: 帰還・スペル 1・スペル 2 をスキル1 の画面中央側に横一列で並べる。下部のヒーローパネルは顔・HP/リソース・装備 6 枠だけの小さな札にし、スペル列のすぐ内側へ寄せた（スティック側と画面中央を空ける）。
- 通常攻撃は斜めのクリスタルの枠、優先対象の小ボタンは暗いガラスにシアンの絵柄。スキルは暗い丸に細い縁と外周の目盛り。スティックはシアンのノブ。
- 上中央のスコアは 青のキル | 時計 | 赤のキル の 3 つの札。ミニマップは角の小さい正方形に金の細い縁。
- 頭上の HP バー: レベルは丸い章、ヒーローの HP に一定量ごとの区切り目盛り（最大 6 本を使い回す。最大 HP が変わった時だけ並べ直す）。
- 死亡中は味方の一覧（パネルより幅が広い）の横へおすすめ購入を移す。詠唱バーの幅はパネルに合わせる。

## 観戦の操作

- 下部の観戦ドック: 一時停止、速度（0.5/1/2/4/8 倍）、視界（全体 / Blue / Red）、自動カメラ、HUD を隠す、前後のヒーロー、10 人の追従ボタン（44pt 以上）。iPhone SE など狭い画面では引き出しに収める。
- 再生バー: ドラッグでシーク、±10/30 秒、最初から、一時停止中のコマ送り、次の見どころ。キル・構造物・目標の印と、計算済みの範囲を表示する。オンラインの観戦席は LIVE と遅延秒数だけを出す。
- 画面の操作: ドラッグで自由カメラ、ピンチで倍率（0.7〜2.5）、ダブルタップで追従に戻る。手動で動かすと自動カメラは 10 秒控える。
- 情報パネル: 追従中のヒーローの詳細、ゴールド/経験値の差のグラフ、目標のタイマー、イベント一覧（タップでその時刻へ）。スコアボードの行をタップすると追従する。
- 死亡中（プレイヤー）: 小型の復活秒数／詳細ボタンと横スクロール可能な味方一覧を出し、タップでその味方を見られる（敵は不可）。「自動」で戦っている味方を追う。

## 過去のミニマップ改修時の確認

`HUDMinimapPrecisionTests`に投影の往復、境界交点、カメラの逆投影、停止中のカメラ更新、敵の最終目撃、描画補間、キャンプの視界制御の回帰テストを追加した。`HUDTacticalMapTests`は4画面サイズ・左右配置・安全領域・操作解除と復帰、`HUDTacticalMapUITests`は拡大・ドラッグ・閉じる操作とスクリーンショットを対象にする。

Windows上でSwift構文解析、投影計算の数値確認、差分検査を実施。SwiftUI/RealityKitの型検査、XCTest、実画面の描画確認はmacOS/Xcodeで実行が必要。

```sh
cd VELSTRIA
xcodegen generate
xcodebuild -project VELSTRIA.xcodeproj -scheme VELSTRIA \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:VELSTRIATests/HUDMinimapPrecisionTests \
  -only-testing:VELSTRIATests/HUDTacticalMapTests \
  -only-testing:VELSTRIATests/HUDLayoutTests \
  -only-testing:VELSTRIATests/HUDAimTests \
  -only-testing:VELSTRIATests/RenderLogicTests \
  -only-testing:VELSTRIAUITests/HUDTacticalMapUITests \
  -only-testing:VELSTRIAUITests/BattleHUDUITests \
  test CODE_SIGNING_ALLOWED=NO
```

シミュレータ名はインストール済みの機種に合わせる。画面確認では明暗の異なる戦場、左利き、色覚対応、観戦一時停止、マップ端、通常/拡大表示を確認する。

## 2026-10-12 スキル番号と強化段階

- 右下の数字は `SkillSlot.rawValue` の固定番号（1・2・3）。現在段階やCDを参照しない。
- 外周は `HUDSkillSnapshot.rank` とゲーム本体の `SkillSlot.maxRank` に接続。現行の通常スキルは4区画、必殺技は3区画。未習得区画も青灰色で表示し、時計回りにシアン点灯する。
- 強化成功で増えた区画のみ短く明るくする。CDと再使用窓のリングは内側に分離。習得可能な未習得スキルは鍵を表示せず、既存の＋操作を維持。
- スキル直径は50→64pt、必殺技52→66pt（共通倍率適用前）。通常攻撃は既存の武器シンボルとシアン多角形枠。スキル種別ごとの既存シンボルを維持。
- 拡大に合わせてスキルと＋の配置を調整。バランス・ワールド・カメラ・入力コマンドは変更なし。
- 強化前後の単体画像は、練習場の実際の強化コマンドを処理したHUDをImageRendererで描画したもの。画面全体はシミュレータのスクリーンショット。
- 実機の複数指同時入力と全ヒーローの目視確認は未実施。
