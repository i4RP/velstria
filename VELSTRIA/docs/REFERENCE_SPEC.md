# 参照仕様（モバイル MOBA 2016 / 2020–21 の数値台帳）

VELSIA の開発基準として取り込んだ外部資料の要点と数値の台帳。**ゲーム内の正本は `DESIGN.md` / `Balance.swift`**。
本書はそこへ反映する「目標値の出どころ」を記録する。差分と実施順は `REFERENCE_GAP.md`。

## 0. 資料の性質（重要）

- 3 資料とも ChatGPT が公開パッチノート（Liquipedia / Fandom / ONE Esports 等）から復元したもの。**開発元の社内仕様書ではない**。
  - ① 初期開発仕様書 復元 v0.1（2016〜2017/1）
  - ② Project NEXT 開発仕様書 復元版（2020–2021）
  - ③ 戦場の数値仕様（41 項目、Patch 1.5.16 / 1.5.38 / 1.5.46 / 1.5.70 / 1.5.88）
- 数値は複数パッチの寄せ集めで、単一パッチの完成仕様ではない。③自身が原典の再検証をしていないと明記している。
- **方針（ユーザー決定）**: 数値は縮尺換算せず資料の値をそのまま採用する。ただし下記の確度タグ「要確認」は推測で埋めない。
- 用語: 資料の固有名（Turtle / Lord / Retribution / Lithowanderer / Blessing / Project NEXT 等）は使わず、
  VELSIA の名称（星喰竜 / 古環の巨像 / 狩猟印 …）で実装する。

確度タグ: **[確認]** パッチノートで確認 / **[復元]** 複数変更からの強い推定 / **[推定]** 設計思想の逆算 / **[要確認]** 単位・条件が未確定。

## 2. 2016 初期仕様（①、[確認]/[復元]）

- 5v5、約 10 分、マッチング約 10 秒、3 レーン、ジャングル 4 区域、ボス 2、タワー計 18（1 チーム 9 = 3×3）。勝利条件は敵本拠地破壊。
- 左スティック + 右スキルの 2 本指操作。オートロックとターゲット切替。装備はどこでも購入可（帰還不要）。
- 後から追加された物（初期 MVP に不要）: ラストヒットボーナス、ランク、エンブレム、フレンド、カスタム装備。
- 後半ほどリスポーン時間が延びる（終盤の決着圧）。最大 Lv は 15 の見込み（[要確認]）。
- MVP 目標: 6 ヒーロー・4 スキル/ヒーロー・装備 10〜15・10 分で面白いこと。
