# 2026-10-19 参照ステージ

添付26画像（IMG_6685〜IMG_6723、欠番あり）と短い動画を参照し、通常マップを置き換えた。
`tools/map_proto/field_annotations.json` に13ブッシュ・17岩壁の地面輪郭を1368×630の画素座標で記録し、反対側へ180度回転する。
ボス周辺も同じ反転で配置する。草むらは26区域、壁は通常34個とボスの巣2個。
描画と隠蔽判定は共通の16.2cm格子。古い1枚画像用の生成器は削除した。

通常プレイの既定レンズは俯角46.1195°、垂直FOV32.3710°、距離17.6680m、前方ずらし1.25m。
画像間の地面特徴点513組から共通レンズを推定した。地面の推定残差中央値6.66cmは、画像全体の一致率ではない。
飛行中のIMG_6698は参照自体が引いた画面なので、共通の岩11点から距離倍率1.32449を別途求めた（残差中央値3.02cm）。撮影倍率だけに適用する。
岩の上端や葉先を地面として逆投影せず、手作業で見積もった接地輪郭を用いる。

## 生成と確認

```sh
uv run --with pillow --with numpy python tools/map_proto/field_layout.py
uv run --with pillow python tools/stage/field_shots.py SIMULATOR_UDID APP_PATH
uv run --with pillow python tools/stage/compare_field.py
```

`field_camera.json` は全26地点の撮影位置と倍率を保存する。
`-stageShot IMG_6713 -stageReview` は通常と同じレンズで撮影し、Documents/stage-review.txtの画像名で撮影地点を切り替えるDebug専用機能。
ヒーローはH028。カメラ・描画用の位置だけ変更し、戦闘判定は変えない。
実画面が表示されるまで待ち、各地点で3秒静止してから撮る。

`build/stage/reference-20261019/review/index.html` に全26組の並列、50%重ね合わせ、差分、透明度スライダーを出力する。
中央切り出しと等倍比率のリサイズだけを使い、画像を局所的に変形しない。
添付元画像の2736×1260で出力し、元画像・実画面のSHA256をmanifest.jsonに記録する。ユーザーの元画像はGitに入れない。

## アセット

[生成元画像と制作記録](../tools/stage/references/field/README.md)。4モデルをTripoで新規生成し、合計18,499三角形の素材へ焼いた。
配置時に材質別12mチャンクへ結合。既存の三角形予算と2048×1024アトラス上限を維持する。
壁の変形で入口を横断する三角形を除外する。草むら・ボスの巣は既存の生成済み素材を利用。
地面の短い草と岩もImageGenから作成。川は青灰色へ明るくし、中央でも川底を残した。
東側の蟹からレーンへ続く岸はIMG_6720の接地位置を逆投影し、反対側にも同じ境界を適用する。
