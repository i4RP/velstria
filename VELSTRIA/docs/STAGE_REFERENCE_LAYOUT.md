# 2026-10-17 添付画像の配置

入力は 1080×592 のステージ右奥画像。`tools/map_proto/reference_layout.json` に、岩の地面での輪郭・背の高い草の範囲・塔・通常キャンプを画素座標で記録した。緑色による自動分類ではない。反対側はマップ中心を基準に180度回転する。

`tools/map_proto/reference_layout.py`（Python + Pillow）で `StageReferenceLayout.swift` を生成する。壁は既存の滑らかな多角形、草むらは16.2 cm格子を使用し、描画と衝突・隠蔽判定を共有する。ピンク部分の低い石は高さ23 cmの歩ける装飾。岩の苔には隠蔽判定を付けない。

タートル・ロードの位置と、その周囲9 mの既存壁・草むらは並行作業の担当範囲として保持する。ボスのモデル・巣のサイズはこの変更では調整しない。

## 比較カメラ


注視点は地図座標 `(61.03907433, 64.19554158) m`、距離176.29678531 m、俯角36.80944726度、垂直画角13.86622334度。通常プレイのカメラ設定は変えない。比較時だけHPバーを隠して霧を外す。

`python tools/stage/compare_layout.py reference.png capture.png build/reference-layout/final` で並列・半透明重ね合わせ・差分・輪郭重ね合わせを出力する。

シミュレータの横画面を中央で1080:592に切り出して比較する。画面全体を縦横別倍率で変形しない。塔の台座を基準にカメラを合わせ、見える8基は画像の測定位置へ移動した。反対側も同時に更新する。

- ピンクの床2点と点対称の2点: ヒーロー半径で通行可能、草むらではない。
- レーン・塔・キャンプのクリアランス、各キャンプの全モンスター出現点、拠点からの到達性。
- 既存のStageTestsによるチャンク・三角形の予算。上限は変更しない。
- 実機FPSはこの作業では測定していない。

素材・塔モデル・照明は既存のものなので、参照画像とピクセル単位では一致しない。元画像はコミットせず、ローカルの `build/reference-layout/` に比較画像を出力する。
