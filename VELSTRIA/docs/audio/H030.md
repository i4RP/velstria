# H030 ライナ（MLBB: ライラ）のスキルの音

作り方: `python tools/audio/make_sounds.py H030`（`tools/audio/heroes/h030.py`）。素材はすべて Sonniss GDC Game Audio Bundle の
実際の録音（砲・銃・機械の装填・高圧の放電・電気のうなり・体への着弾）。電子音・SF のレーザー・合成の音は使っていない。
加工した完成品だけを置く（原本はリポジトリに入れない）。どの素材集を使ったかは [SOURCES.md](SOURCES.md)（自動生成）。

## なぜこの材質か

MLBB のライラは「星の砲（マレフィック・ガン）」を抱えた射手で、弾・球・ビームはどれも青い電気のエネルギー（演出は
[docs/vfx/H030.md](../vfx/H030.md)。青と水色の白、紺の電光）。「ピュン」というレーザーではなく、
**砲そのものの発射音（機関砲・戦車砲・榴弾砲・空気砲）+ 機械の装填の音 + 本物の高圧放電（弧・火花・変圧器のうなり）**で、
重い砲から電気の弾が出る音にした。命中は放電の弾けに、弾が体に当たる音と低い芯を足した。

## 時刻（sim と演出）

0 秒 = 発動（skillCast）・命中（damage）のイベント。打撃の層は `hit=True` / 弾けの位置合わせ（`crack()`: 長い放電の録音から
指定した時刻あたりの弾けを探し、その立ち上がりを置いた時刻に揃える）で、判定の時刻にちょうど来るように置いた。

| スキル | sim（`Kit_H030`） | 演出（`FX_H030`） | 音の山 |
|---|---|---|---|
| S1 遠星弾 | 0.1 秒で発射、弾は 1950/秒・最大 755（0.39 秒） | 電光 0.04、閃光 0.1、電光の帯 0.19 | 発射 0.10〜0.11 秒 |
| S2 星爆弾 | 0.1 秒で発射、1050/秒・最大 384（0.37 秒）、着弾で爆発 | 星の閃光 0.1 | 発射 0.10〜0.11 秒。爆発は命中の音 |
| 奥義 星砕の大砲 | 0.55 秒でビーム（7000/秒、ほぼ即着） | 照準 0.08、溜めの球 0.17、金の芯 0.40、閃光 0.47、ビーム 0.55〜0.95 | 溜めが 0.2〜0.5 秒でふくらみ、発射 0.56 秒が最大 |

## 確かめたこと・まだのこと

- 4 帯域（低音 30〜120 Hz・体 120〜600・金属 600〜3000・擦れ 3000〜12000）の 0.1 秒ごとの大きさで、発射・爆発・命中の山が
  判定の時刻（S1・S2 0.1 秒、奥義 0.55 秒、命中 0 秒）に来ること、山が -1 dBFS を越えないこと、奥義の溜めが発射より小さいことを確かめた。
- MLBB のライラの効果音だけの録画はまだ無い。音量はロームの測定の物差し（発動 -20.5・命中 -23）で、MLBB との帯域の比べはしていない。
  録画をもらえたら、S1・S2・奥義を 3 回ずつ（効果音 100・BGM 0・ボイス 0）で詰める。
- 実機（iPhone のスピーカー）での聞こえ方は未確認。
