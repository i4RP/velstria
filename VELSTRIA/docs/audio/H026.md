# H026 エウリア（MLBB: エウドラ）のスキルの音

作り方: `python tools/audio/make_sounds.py H026`（`tools/audio/heroes/h026.py`）。素材は Sonniss GDC Game Audio Bundle の録音だけ。
層は「溜め → 放つ → 命中の芯 → 材質の余韻 → 低音」の順に 4〜11 枚、打撃の層は立ち上がり（`hit=True`）を sim の時刻に揃えた。
長い放電の録音（`surge_discharge…`）は、使う区間を切ってからその中の立ち上がりを揃えた（`burst()`）。音量はロームの測定
（[MLBB_H029.md](MLBB_H029.md)・[MLBB_H034.md](MLBB_H034.md)）を物差しにした（エウドラの MLBB の録画はまだ無い）。

エウドラに合わせた考え方: 雷の魔導士なので、**本物の雷鳴**（間近の落雷の裂ける音・遠くへ転がる雷鳴・深い雷の低音）と、
**高電圧の放電の録音**（アーク溶接の火花の弾け・高電圧のアーク・湿った放電・電撃殺虫器の弾け・変圧器のうなり）だけで作った。
「ビリビリ」の合成音・SF の光線・電子音は使っていない。扇の稲妻と落雷は「裂ける音（擦れ・金属の帯）+ 雷の体（体の帯）+ 低音」、
命中は「火花の弾け（立ち上がり 0.01 秒）+ 放電のぱちぱち + 体を打つ低い芯」。

## sim の時刻（`Kit_H026` の Tune・`FX_H026.swift`・[docs/vfx/H026.md](../vfx/H026.md)）

| スキル | 時刻 |
|---|---|
| S1 分岐雷 | 0 秒に発動、0.05 秒に扇の稲妻（初撃のダメージ）。超伝導の敵は 0.12 / 0.39 / 0.66 / 0.93 秒の継続と 1.0 秒の終わりの一撃（0.27 秒おきに命中の音） |
| S2 雷球 | 0 秒に投げる（毎秒 1150、最大 0.44 秒飛ぶ）。当たった時と、広がった敵ごとに命中の音 |
| 奥義 九天雷鳴 | 0〜0.43 秒に足元の電弧、0.41 秒に縦の大雷、0.45 秒に落雷（ダメージ）、+0.14 秒（0.59）に外側の雷。超伝導の敵は 0.83 秒後に炸裂（奥義の命中の音） |
| パッシブ 超伝導 | 印の合図（実演用の演出）。試合ではバッジが無いので鳴らない |

## 確かめていないこと

- MLBB のエウドラの効果音だけの録画が無いので、時刻は sim と演出、音量はロームの物差し。録画をもらえたら詰める。
- 実機で聞いていない。放電の録音（surge discharge）は体の帯（120〜600 Hz）のうなりが強いので、-6〜-8 dB に下げ、火花とアークで擦れの帯を足した。
- パッシブの音は、今は試合では鳴らない（パッシブのバッジが無く、演出は実演用だけ）。
