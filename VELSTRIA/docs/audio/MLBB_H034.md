# H034 ゴルムの音と MLBB（フランコ）の比較

参照: MLBB の効果音だけの画面収録（効果音 100・BGM 0・ボイス 0、練習モードで CPU の英雄相手、68 秒・30 fps。アップロードが切れて最後の約 2 秒は
壊れている。2026-10-18 にユーザーから受け取った）。録画と、そこから切り出した音・コマは手元だけに置き、リポジトリには入れない。

測り方は [MLBB_H029.md](MLBB_H029.md) と同じ。比べる音は、発動の音と命中の音（自分の命中 0.8 倍）を sim の時刻に重ねたもの:
- S1: 投げは 0.33 秒、命中は 1.03 秒（録画の命中に合わせた飛ぶ時間）。
- S2: 叩きつけ 0.27 秒。
- 奥義: 0.25 + 0.32n 秒に 6 撃。
MLBB の音は、投げ・叩きつけ・掴みの時刻に合わせてずらす（S1 +0.13・S2 +0.2・奥義 +0.25）。

## 作った音（tools/audio/make_sounds.py（heroes/h0xx.py） `h034`。素材は Sonniss GDC の録音）

| 音 | 層 |
|---|---|
| 通常攻撃 ×4 | 両手斧が肉に食い込む打撃（着弾を 0.04 秒に）・低い芯・鎖の鳴り |
| 通常攻撃の命中 ×3 | 肉を打つ鈍い音（平手・革の打撃・重いパンチ）+ 低い打撃 |
| S1 発動 | 鎖を回す音がふくらむ → 0.33 秒の投げ（縄の風切り・鎖の放り出し・低い芯）→ 飛ぶ鎖の連なり（鎖の動き・重い鎖・鎖の鈴なり・金属の通り過ぎ・低いうなり）→ 1.05 秒で消える |
| S1 命中 ×3 | 鉤が刺さる重い打撃（深いパンチ・体の砕け・金属の打撃・低音）+ 低音の尾 → 0.45 秒後に鎖を引く（鎖の落下・重い鎖・掴んで投げる音・鞭の擦れ・鎖の動き） |
| S2 発動 | 斧を振り上げる風（0.15 秒に山）→ 0.27 秒の叩きつけ（深い打撃・低音・土への落下・金属の叩きつけ・岩の砕け・小さな炎）→ 低音の尾 → 1.05 秒で消える |
| S2 命中 ×3 | 衝撃が体に当たる鈍い音 + 土 |
| 奥義 発動 | 0.25 秒の掴み（鞭の一閃・掴んで投げる音・鎖・低音）→ 拘束の間の掴み合いの擦れ（首を締める音）と骨の砕け → 2.05 秒で消える |
| 奥義 命中 ×3（6 撃で順に） | 拳と斧の重い打撃（深いパンチ・重いパンチ・体の砕け・肉の潰れ・深い傷）+ 低音の芯 + 鎖の跳ね |
| パッシブ | 闘気がたまり始める時に 1 回: 逆再生の低い打撃で 0.5 秒かけてふくらむ低音 + 光のきらめき |

## 比べた結果（MLBB との差: 4 帯域の 0.1 秒ごとの差の絶対値の平均、dB）

| 音 | 長さ MLBB / 自作 | LUFS MLBB / 自作 | 低音 | 体 | 金属 | 擦れ | 平均 | 前（v1）の平均 |
|---|---|---|---|---|---|---|---|---|
| S1（投げ〜命中〜引き寄せ） | 1.80 / 1.70 | -20.2 / -21.3 | 8.7 | 5.2 | 6.7 | 8.4 | 7.2 | 17.9 |
| S2 | 0.84 / 0.79 | -19.8 / -20.0 | 3.9 | 5.5 | 2.7 | 3.2 | 3.8 | 6.7（尾が 2.4 秒鳴り続けていた） |
| S2（2 回目） | 0.80 / 0.79 | -19.4 / -20.0 | 5.6 | 4.5 | 5.2 | 3.5 | 4.7 | 7.9 |
| 奥義（6 撃） | 2.37 / 2.17 | -13.8 / -13.5 | 7.0 | 7.0 | 4.9 | 6.1 | 6.3 | 20.2（4 dB 小さかった） |
| 奥義（2 回目） | 2.46 / 2.17 | -13.3 / -13.5 | 8.2 | 7.3 | 5.1 | 5.4 | 6.5 | — |
| パッシブ | 1.10 / 1.04 | -21.5 / -22.0 | 3.1 | 6.5 | 2.2 | 3.3 | 3.8 | （v1 は無し） |

合った所:
- 長さ・音量。奥義が一番大きく、ほかより 6 dB 上。
- 投げ → 鎖の連なり → 命中 → 引き寄せの並び。引き寄せが命中より明るく大きいこと。
- S2 の短い芯と低音の尾。
- 奥義の掴みの一閃と、打撃の間も途切れない掴み合いの音。
- パッシブの低音のふくらみ。

残った所:
- S1 の飛ぶ時間。sim の鉤は最大 0.54 秒、録画は遠い相手で 0.7 秒。飛ぶ鎖の音は最大の射程の長さで作っていて、近い命中では命中の音と重なる。
- S1 の命中の後の低音が 0.1 秒短い（-16 dB）。
- 奥義の低音は打撃の山の間で 3〜8 dB 大きい。
- 通常攻撃は MLBB の単独の音で確かめられていない。録画を頼むなら、効果音だけで、敵の塔から離れて CPU の英雄に通常攻撃を 5 回ほど。
- S1 が外れた時の「鎖が戻る音」は無い。発動の時には当たるか分からず、外れのイベントも無いので鳴らせない。

実機で見てほしい所:
- 鉤の投げ・命中・引き寄せの音と、画（鎖が張る・縮む）の時刻。
- 奥義の 6 撃が毎回少し違って聞こえること。
- パッシブの音が、たまり始めの 1 回だけ鳴ること（毎秒は鳴らない）。

モーション（docs/vfx/H034.md「モーション（打撃の時刻）」）に合わせた振りの音: S2 の振り下ろし（0.21〜0.27 秒）の風の山を 0.22 秒に、
奥義の 2〜5 撃の振りの風（撃の 0.05 秒前に山）、6 撃目の振り上げ（1.53〜1.61）と地面に当たる音（1.68）。
