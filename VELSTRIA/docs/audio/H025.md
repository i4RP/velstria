# H025 ルミナ（MLBB: ミヤ）のスキルの音

作り方: `python tools/audio/make_sounds.py H025`（`tools/audio/heroes/h025.py`）。素材は Sonniss GDC Game Audio Bundle の録音だけ
（電子音・合成音・SF の音は使っていない）。層は「溜め → 放つ → 命中の芯 → 材質の余韻 → 低音」の順に 3〜7 枚、打撃の層は
立ち上がり（`hit=True`）か山（`hit="peak"`）を sim の時刻に揃えた。音量はロームの測定（[MLBB_H029.md](MLBB_H029.md)・
[MLBB_H034.md](MLBB_H034.md)）を物差しにした（ミヤの MLBB の録画はまだ無い）。通常攻撃の音は武器ごとの組で別に作る。

ミヤに合わせた考え方: 月の弓使いなので、主役は **弓と弦（張る・放つ）と矢の風**、色づけは **月光 = ガラス・風鈴・シンギングボウルの澄んだ響き**、
S2 の檻は **氷（ひび・砕け・霜）**。光る演出でも「ピュン」「キラリン」の電子音にせず、澄んだ響きを持つ実物（ガラス・金属のボウル・風鈴）で鳴らす。

## sim の時刻（`Kit_H025` の LuminaTuning・`FX_H025.swift`・[docs/vfx/H025.md](../vfx/H025.md)）

| スキル | 時刻 |
|---|---|
| S1 月弦分矢 | 自己強化。0.04 秒に肩の閃光、0.04〜0.34 秒に青い気。矢は通常攻撃のたびに飛ぶ（スキルの命中の音は無い） |
| S2 月蝕の矢 | 0〜0.267 秒に弓を天へ引き、0.267 秒に放つ。0.65 秒に着弾（ダメージ・バインド）、0.98 秒に小さな矢 6 本が散る |
| 奥義 隠れ月光 | 0 秒に姿が薄れ、0.03〜0.45 秒に三日月、0.05〜0.53 秒に光の柱。ダメージは無い（命中の音は無い） |
| パッシブ 月環の導き | 段が増えた時の小さな閃き（演出が 3 秒止んでいた時だけ鳴る） |

## 確かめていないこと

- MLBB のミヤの効果音だけの録画が無いので、時刻は sim と演出、音量はロームの物差し。録画をもらえたら MLBB_H029.md と同じ方法で詰める。
- 実機で聞いていない（帯域の大きさ・長さ・時刻は数値で確かめた）。
- `Vaeyanbow …mythic`・`Hawk's Arrow` は弓の録音を素材集の側で整えた音（電子音ではない）。`Hawk's Arrow` は低音を切って風の部分だけ使った。

## 2026-10-23 品質更新

S2の離弦を16/60秒へ同期。原録音のローカルキャッシュが無かったため、同梱済みのミックスを
`tools/audio/retime_h025_s2.py` で再配置した。離弦の主要な波形は速度を保って53.33ms前へ移動し、
前の擦れと後の余韻の一部で時間を吸収した。0.65秒以降（着弾・分裂）のPCMは変更前と完全一致。
元のレイヤー再生成レシピにも同じ離弦時刻を記録。原録音からの再ミックスと実機での聴感評価は未実施。
