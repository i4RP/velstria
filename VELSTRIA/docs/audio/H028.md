# H028 ザイル（MLBB: セイバー）のスキルの音

作り方: `python tools/audio/make_sounds.py H028`（`tools/audio/heroes/h028.py`）。素材は Sonniss GDC Game Audio Bundle の録音だけ
（電子音・合成音は使っていない）。層は「溜め → 振り → 命中の芯 → 材質の余韻 → 低音」の順に 4〜15 枚。打撃の層は立ち上がり
（`hit=True`）を、振りの層は風の山（`hit="peak"`）を sim の時刻に揃えた。音量はロームの測定（[MLBB_H029.md](MLBB_H029.md)・
[MLBB_H034.md](MLBB_H034.md)）を物差しにした（セイバーの MLBB の録画はまだ無い）。通常攻撃（S2 の強化通常攻撃を含む）の音は武器ごとの組で別に作る。

セイバーに合わせた考え方: 飛ぶ剣の暗殺者なので、主役は **刃が空を切る鋭い風**（長い刃・ナイフの振り）と **鋼の鳴り**
（抜く・ばねの弾け・刃のきらめき・刃が輪に収まる鳴り）、命中は **肉と鎧を断つ斬撃**（刃の打ち合い・刃が肉に食い込む・鋼の擦れ）。
S1 の回る剣は **短い刃の風切りが少しずつ薄れながら続く** 形、奥義は **3 つの振り（3 撃目が重い）** で畳みかける。

## sim の時刻（`Kit_H028` の Tune・`FX_H028.swift`・[docs/vfx/H028.md](../vfx/H028.md)）

| スキル | 時刻 |
|---|---|
| S1 環剣 | 0〜0.2 秒に剣を一回し、0.2 秒に 5 本が飛び出し、0.47 秒に輪に着いて 4.8 秒回る。接触（0.47 秒から 0.48 秒おき）と剣撃が命中の音 |
| S2 断空突進 | 3m を 0.2 秒で駆け、通り道の敵に命中の音。着いたら刃に赤い光 |
| 奥義 三連断空 | 突進（動画 0.14〜0.19 秒）→ 到着・+0.39・+0.78 秒に 3 連撃（命中の音）。演出の斬撃は 0.2 / 0.59 / 0.98 秒 |
| パッシブ 空断の理 | 防御ダウンの層が増えた時（3 秒止んでいた時だけ鳴る） |

## 確かめていないこと

- MLBB のセイバーの効果音だけの録画が無いので、時刻は sim と演出、音量はロームの物差し。録画をもらえたら詰める。
- 実機で聞いていない。奥義の 3 撃は突進の長さで最大 0.15 秒ほど前後する（発動の振りは演出の 0.2 / 0.59 / 0.98 秒。命中の音は sim の時刻どおり）。
- S1 の回る剣の音は発動の音の中の 1 秒だけ（4.8 秒回り続ける間の音は無い。続けるには鳴らし方の側の仕組みが要る）。
