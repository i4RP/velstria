# 武器ごとの通常攻撃の音と、戦闘の共通の音（2026-10-20）

ユーザー指示（2026-10-20）: 「ちゃちい今のピヨピヨした音じゃなくて、武器ごとのリアルな音でいきたい」。戦闘の効果音から合成（SFXSynth）と
電子音・SF の音を外し、すべて実音の録音（Sonniss GDC。どの録音を使ったかは [SOURCES.md](SOURCES.md) の出力の表）にした。
ファイルが無い効果音は鳴らさない（合成は保険にも使わない）。作り方は `python tools/audio/make_sounds.py weapons common`
（`tools/audio/sets/weapons.py`・`sets/common.py`）。

## 武器の組（`App/Services/HeroWeaponSounds.swift` が 34 体に割り当てる）

1 つの組 = 通常攻撃 4 種（`wpn_<組>_atk_1..4`）・命中 3 種（`_hit_1..3`）・会心 2 種（`_crit_1..2`）。鳴らすたびに順に替える。
近接は通常攻撃の音が sim の命中（`attackReleased`）の瞬間に「振りの終わり → 刃・打撃の芯」、命中の音は当たった側の鳴り。
遠隔は通常攻撃の音が発射、命中の音は着弾。会心は命中の代わりに鳴る。固有の音（H029・H034）があればそちらが先。

| 組 | ヒーロー | 通常攻撃 | 命中 | 会心 |
|---|---|---|---|---|
| sword（剣） | H001・H002・H020・H028 | 刃の風切り（ナイフの振り）→ 斬りの芯（剣の斬撃の録音 4 種）→ 刃の鳴り | 刃が肉に入る音 + 体への衝撃 | マチェットの鋭い鳴り + 深い斬り + 低い芯 |
| greatsword（大剣） | H032・H033 | 重い武器の振り → 両手斧の肉への斬り → 低い芯 | 重い刃の刺さり + 骨の砕け | 深い斬り + 低い刃の鳴り + 低音 |
| dual（双剣） | H006・H012・H014・H018・H022・H024 | 短い刃の風切り → 軽い斬り（刃の連打）→ 刃の鳴り | 刃が肉を裂く短い音 | 二連の斬り + 深い刃 + 鳴り |
| spear（槍） | H008・H027 | 竿のうなる風切り → 穂先の刺さり → 柄の木の鳴り | 刺さる音 + 体への衝撃 | 深い刺突 + 鳴り + 低い芯 |
| fist（拳） | H007 | 拳の風切り（手袋の振り）→ 拳の打撃 → 体への衝撃 + 岩の擦れ | 体を打つ鈍い音 | 重い打撃 + 骨の砕け |
| hammer（鎚） | H013・H019・H029 | 重い振り → 鉄・石の鈍い打撃 → 低い芯 | 体への重い衝撃 + 砕け | 巨大な鎚の打撃 + 重い一撃の残響 |
| chain（鎖鉤） | H034 | 縄・鎖の風切り → 鉤の打撃 → 鎖の鳴り | 鎖帷子への打撃 + 体への衝撃 | 鎖の重い打撃 + 深い鉤 |
| bow（弓） | H003・H025 | 弦の鳴り → 矢の風切り | 矢の刺さり + 肉の鈍い音 | 深い刺さり + 鏃の鳴り |
| crossbow（弩） | H009 | 弦の弾け + 機構の金属音 → 矢の風切り | 太矢の刺さり + 金属の跳ね | 深い刺さり + 鏃の鳴り |
| gun（銃） | H015・H021 | 実銃の発射と残響（狙撃銃・回転式・散弾） | 弾が肉に当たる音 + 金属の跳ね | 重い着弾 + 衝撃 |
| cannon（砲） | H030 | 機関砲・戦車砲の発射と残響 + 溶接の火花の弾け | 砲弾の着弾 + 電気の弾け | 大きな着弾 + 低音 + 放電 |
| magic_water（水） | H004 | 水の弾け + 柔らかい風切り | 水の当たり | 大きな水しぶき + 低い芯 |
| magic_fire（炎） | H010 | 松明の炎の風切り + 炎の弾け | 火の着火の弾け | 大きな火の弾け + 低音 |
| magic_lightning（雷） | H005・H023・H026 | 放電（電撃殺虫器）の弾け + 溶接の火花 | 高電圧の放電 | 本物の雷鳴の割れ + 放電 |
| magic_light（聖） | H011・H016 | 鐘の澄んだ鳴り + 柔らかい風切り | 鐘の打音 + 鈍い衝撃 | 銅鑼の一撃 + 重い衝撃 |
| magic_dark（闇） | H017 | 暗い気の放ち + 低いうねりの風 | 低く重い衝撃 | 暗い金属の衝撃 + 低いうねり |
| magic_ice（氷） | H031 | 氷の澄んだ打音 + 冷気（ドライアイス）の擦れ | 氷が砕ける音 | 大きな氷の割れと砕け |

鳴らし方（`BattleAudioDirector`）: 自分（観戦は追従中のユニット）の通常攻撃・命中は今までの音量で、ほかのヒーローの通常攻撃と命中は
聞こえる距離の 6 割まで距離で弱め（0.32・0.26 倍から）、0.07 秒より詰まる時は間引く。自分が受けた通常攻撃の命中は 0.55。

## 戦闘の共通の音（`sets/common.py`。`AudioFiles.sfx`）

| 音 | 素材 |
|---|---|
| 汎用の近接・遠隔攻撃・命中・会心（武器の組の無いユニットの保険） | 剣・弓の組と同じ録音 |
| 汎用のスキル・奥義の発動（固有のスキルの音の無いヒーロー） | 渦の風 → 衝撃 / 大きな溜めの風 → 重い一撃 + 金属の低音 |
| 回復 | 磁器の風鈴 + 柔らかい風 |
| シールド | 盾の受けの金属 + 回る盾の響き |
| 死亡 | 体が地面に倒れる音 + 低いブーム + 暗い金属の尾 |
| キル / 連続キル | 刃の鋭い鳴り + 一撃 + 抜き身の刃 / 銅鑼 + 重い一撃 + 刃の鳴り |
| 塔の破壊（告知） | 爆発 + 建物の崩落の石 + 低いブーム |
| 目標（ドラゴン等） | 角笛のブラーム + 銅鑼 |
| ゴールド | 硬貨の鳴り（3 種） |
| リコール / 復活 / レベルアップ / 告知 | 柔らかい風 + 風鈴 / 鉢（シンギングボウル）の一打 + 風 / ベルツリー + 鉢 / 銅鑼の一打 |
| 塔の立ち上がり・ロック・亀裂・倒壊・着地、結晶の消失 | 地鳴り + 石の擦れ・重い鉄 + ボルト・石の打撃 + 割れ・石の崩落 + 低音・地面への衝撃・水晶のグラスの鳴り + ガラス |

戦闘の BGM（`MusicComposer` の合成の曲）はまだ合成のまま（効果音ではないので今回は変えていない）。
