# H029 ボルグの音と MLBB（ティグラル）の比較

参照: MLBB の効果音だけの画面収録（効果音 100・BGM 0・ボイス 0、練習モードで CPU の英雄相手、44 秒・30 fps・AAC 44.1 kHz ステレオ。
2026-10-18 にユーザーから受け取った）。録画と、そこから切り出した音・コマは手元だけに置き、リポジトリには入れない。製品の音には使わない。

測り方（[README.md](README.md)「MLBB との比べ方」）: 区間ごとに 4 つの帯域（低音 30〜120 Hz・体 120〜600・金属 600〜3000・擦れ 3000〜12000）
の 50 ms ごとの大きさ、音の長さ（最大から -40 dB まで）、LUFS。自作の音は発動の時刻を 0 として、MLBB の音の始まりを sim の打撃の時刻に
合わせてずらして並べる（S1 +0.2 秒・S2 -0.05・再使用 -0.1・奥義 +0.125・通常攻撃 -0.12）。

| スキル | 時刻（録画） | 長さ | LUFS | 層（材質・時刻） |

| S1 | 2.85 秒 | 1.85 秒 | -21.6 | 叩きつけの体の芯（-17）→ 0.2 秒後に低音の山（-16）→ 0.5 秒続く地鳴り → 叩きつけの +0.65 秒にもう一度の芯と低音（3 波目）→ 1.4 秒で消える。叩きつけの前はほぼ無音 |
| S2 | 9.39 秒ほか 4 回 | 1.3 秒 | -20.6 | 出だしの 0.3 秒に盾の金属・体の芯・突進の風（-17〜-21）、0.3 秒に擦れ、低音は 0.5 秒まで -18〜-21、0.6 秒に押し運びの小さな打撃、1.1 秒で消える |
| S2 再使用 | 18.1 秒ほか 3 回 | 0.85 秒 | -19.7 | 振り上げの風（体 -26）→ 槌の打撃（体 -15、金属 -23）→ 低音の尾 0.4 秒 |

## 作った音（tools/audio/make_sounds.py（heroes/h0xx.py） `h029`。素材は Sonniss GDC の録音）

| 音 | 層 |

| 通常攻撃 ×4 | 重い武器の振り → 鈍い着弾（着弾を 0.04 秒に）・鉄の槌の鳴り・鉄板の鳴り（尾）・低い芯 |
| 通常攻撃の命中 ×3 | 盾・鎧に当たる金属 |
| S1 発動 | 小さな振りかぶりの風 → 0.25 秒の叩きつけ（石の打撃・大槌・体への打撃・岩の崩れ・金属の低音のブーム・洞窟の低音）→ 岩の砕けのざらつき → 0.58 の 2 波（小さく）→ 0.92 の 3 波（岩・体の芯・低音）→ 炎の弾け |
| S2 発動 | 盾の金属・体の芯・突進の風（0 秒）→ 地響き → 0.3 秒の盾の擦れ → 炎の尾 → 0.67 の押し運びの打撃（小さく） |
| S2 再使用 | 振り上げの風（中の着弾を 0.2 秒に揃える）→ 0.2 秒に鉄の槌・大槌・体の芯・低音のブーム |
| 奥義 発動 | 0.22 秒の掲げる一撃（打撃・低音・盾の金属・風）→ 吸い込み（気の流れ・渦の風・地鳴り・逆再生の金属のブーム）→ 1.0 秒の崩落（重い一撃・体の芯・金属の低音・岩・鉄の槌）→ 1.85 秒で消える |
| 命中 ×3（S1・S2・奥義） | 岩の着弾 + 炎 / 盾の打撃 + 体への衝撃 / 重い金属の着弾 + 岩 |
| パッシブ | 盾の加護（光の音 + 盾のきらめき） |

## 比べた結果（MLBB との差: 4 帯域の 0.1 秒ごとの差の絶対値の平均、dB）

| 音 | 長さ MLBB / 自作 | LUFS MLBB / 自作 | 低音 | 体 | 金属 | 擦れ | 平均 | 前（v1・Kenney の合成）の平均 |
|---|---|---|---|---|---|---|---|---|
| 通常攻撃 | 0.45 / 0.38 | -21.9 / -22.6 | 5.6 | 5.5 | 5.3 | 6.8 | 5.8 | （v1 は汎用の音） |
| S1 | 1.85 / 1.36 | -21.6 / -20.5 | 9.5 | 4.4 | 7.9 | 10.6 | 8.1 | 12.5 |
| S2 | 1.31 / 1.28 | -20.6 / -20.5 | 2.7 | 3.5 | 6.0 | 4.8 | 4.2 | 12.3 |
| S2 再使用 | 0.85 / 0.93 | -19.7 / -20.5 | 4.9 | 3.7 | 4.2 | 4.5 | 4.3 | 11.6 |
| 奥義 | 1.77 / 1.53 | -19.7 / -19.0 | 6.3 | 6.0 | 6.4 | 6.1 | 6.2 | 7.0 |

（録画の 2 回目の S1・奥義・1 回目の再使用は、ほかの音（撃破・塔の弾・続けて撃った S2）と重なっていて比べられない。）

合った所:
- 長さと音量（LUFS）。スキルどうし・通常攻撃との大きさの比（通常攻撃 ≈ スキル -1〜-2 dB、奥義が一番大きい）。
- 打撃の時刻。sim の判定（S1 0.25・0.58・0.92 秒、再使用 0.2 秒、奥義 1.0 秒、通常攻撃は命中の瞬間）に着弾がそろう。
- S2・再使用の山の形。出だしの盾の金属、0.3 秒の擦れ、押し運びの小ささ。
- 奥義の出だしの一撃、吸い込みの間の地鳴り、崩落の後の低音の山。

残った所:
- S1 の叩きつけは、MLBB より 1 区間（0.05〜0.1 秒）早い。sim の 0.25 秒に合わせているので直さない。
- S1 の擦れ（3000 Hz 以上）は 0.5〜0.9 秒で 5〜10 dB 小さい。MLBB の岩の砕けの細かい音が、手持ちの素材に無い。
- 奥義の吸い込みの擦れは 4〜13 dB 小さく、崩落の後の金属・擦れが 0.1〜0.2 秒長い。
- 通常攻撃は MLBB より着弾が前に寄っていて、尾の金属・擦れが 6〜10 dB 小さい。MLBB は攻撃の始めに鳴らしていて、0.1 秒ほど振りの音が先にあるらしい。こちらは命中の瞬間に鳴らしている。

実機で見てほしい所:
- 打撃と画の時刻: 叩きつけ・崩落・槌の振り上げ。
- 奥義の時にほかの音が下がって戻ること。
- 左右の定位。
- 通常攻撃の音が毎回少しずつ違うこと（4 種）。

モーション（docs/vfx/H029.md「モーション（打撃の時刻）」）に合わせた振りの音: 奥義の盾と槌の振り下ろし（0.93〜1.0 秒）の風（山 0.97 秒）。
S1 の振り下ろし（0.19〜0.25）・再使用の振り上げ（0.10〜0.30、0.2 で前の低い所）は、振りの素材の中の着弾を判定の時刻に揃えてある。
