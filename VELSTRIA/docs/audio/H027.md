# H027 ジャルド（MLBB: 子龍）のスキルの音

作り方: `python tools/audio/make_sounds.py H027`（`tools/audio/heroes/h027.py`）。素材は Sonniss GDC Game Audio Bundle の録音だけ
（電子音・合成音は使っていない）。層は「溜め → 振り → 命中の芯 → 材質の余韻 → 低音」の順に 5〜10 枚。打撃の層は立ち上がり
（`hit=True`）を、振りの層は風の山（`hit="peak"`）を sim の時刻に揃えた。音量はロームの測定（[MLBB_H029.md](MLBB_H029.md)・
[MLBB_H034.md](MLBB_H034.md)）を物差しにした（子龍の MLBB の録画はまだ無い）。通常攻撃（三連突きを含む）の音は武器ごとの組で別に作る。

子龍に合わせた考え方: 竜の槍なので、主役は **長い柄が空を切る風**（棒・竿・重い武器の振りの録音）と **穂先の鋼の鳴り**、
命中は **肉と鎧を貫く突き**（刃が刺さる・ナイフの刺し・鋼の打ち合い・木の柄・体への打撃）。S1 の放り投げは **体が地に叩きつけられる音**
（土の上の体の落下・鎖と革の鎧）、S2 は **土を蹴る踏み込み**、奥義は **渦を巻く風と太鼓の一打** で武人の気が満ちる音にした。

## sim の時刻（`Kit_H027` の Tune・`FX_H027.swift`・[docs/vfx/H027.md](../vfx/H027.md)）

| スキル | 時刻 |
|---|---|
| S1 跳槍撃 | 発動と同じ tick に命中（命中の音）。0〜0.4 秒は掲げたまま、0.4 秒に頭上を越えて放り、0.6 秒に背後へ着地 |
| S2 竜牙突き | 0 秒に蹴り出し、毎秒 1520 で突進（動画では 0.23 秒で到着）。到着の tick に命中の音 |
| 奥義 至高の武人 | 自己強化 7.5 秒。0〜0.5 秒に風の渦・胸の光・水色の泡。ダメージは無い |
| パッシブ 竜の三連突き | 竜気がたまった時の穂先の閃き（3 秒止んでいた時だけ鳴る） |

## 確かめていないこと

- MLBB の子龍の効果音だけの録画が無いので、時刻は sim と演出、音量はロームの物差し。録画をもらえたら詰める。
- 実機で聞いていない。S2 の到着は突進の距離で 0〜0.3 秒前後する（発動の風の山は動画の 0.2 秒に置いた。打撃は命中の音なので常に合う）。
- `WINDDsgn_Wind, Rush, Whoosh` は風の録音を素材集の側で整えた音（電子音ではない）。
