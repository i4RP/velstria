# H033 ヴァルド（MLBB: アルカード）のスキルの音

作り方: `python tools/audio/make_sounds.py H033`（`tools/audio/heroes/h033.py`）。素材はすべて Sonniss GDC Game Audio Bundle の
実際の録音（大剣の重い振りと刃の擦れ、刃が岩を打つ・土と岩の砕け、肉を斬る音と血しぶき、重い風、遠い雷の地鳴り）。
電子音・合成の音は使っていない。どの素材集を使ったかは [SOURCES.md](SOURCES.md)（自動生成）。

## なぜこの材質か

MLBB のアルカードは大剣の魔物狩りで、跳び込んで地を割り（S1）、大剣を回し（S2）、奥義で周りの力を吸い取って衝撃波を放ち、
斬るたびに吸血する（演出は [docs/vfx/H033.md](../vfx/H033.md)）。
- 大剣: 細い刀の「シュッ」ではなく、低く重い風切り（Weapon Swings の LowSwings・Swing 3 Large）と長い刃の金属の擦れ（SWING SCRAPE）。
- 叩きつけ: 刃が岩を打つ音（石をハンマーで打つ録音）・土と岩の砕け・落ちる岩・刃の金属・土への落下の低音。
- 命中: 肉を斬る・裂く音（首を斬る・深い傷・肉の裂け）と血しぶき、体の芯。
- 吸血: 重い風の逆再生（吸い込み）と血を絞る湿った音。奥義の命中では、斬った後に血が術者へ戻る短い吸い込みを足した。

## 時刻（sim と演出）

0 秒 = 発動（skillCast）・命中（damage）のイベント。

| スキル | sim（`Kit_H033`） | 演出（`FX_H033`） | 音の山 |
|---|---|---|---|
| S1 裂地撃 | 1250/秒で最大 420 跳ぶ（0.34 秒）→ 着地で命中 | 三日月 0.30、着地 0.34 | 振り下ろしの擦れ 0.32 → 叩きつけ 0.34〜0.37 |
| S2 旋回斬 | 即時（命中は 0 秒） | 回転 0.06〜0.3 | 0.06・0.14・0.22 秒の風切り |
| 奥義（1 回目）吸収 | 吸収（ダメージ無し） | 吸収の渦 0.02〜0.32、靄 〜0.55 | 吸い込みが 0.4〜0.55 でふくらみ、0.48 で体に収まる |
| 奥義の再使用 衝撃波 | 0.16 秒の振りかぶり → 1000/秒で 640（0.64 秒）進む。命中は当たった所 | 三日月 0.16 | 振り抜き 0.18 秒が最大、衝撃波の風が 0.85 秒まで |

S1 は近い所へ跳ぶと 0.34 秒より早く着く。発動の音の叩きつけは最大の距離（演出と同じ 0.34 秒）に置き、実際の着地では命中の音が鳴る。

## 確かめたこと・まだのこと

- 4 帯域の 0.1 秒ごとの大きさで、叩きつけ（0.34 秒）・振り抜き（0.16 秒）・命中（0 秒）に山が来ること、山が -1 dBFS を越えないこと、
  吸収の吸い込みが 0.5 秒に向けてふくらむことを確かめた。
- MLBB のアルカードの効果音だけの録画はまだ無い。音量はロームの測定の物差しで、帯域の比べはしていない。
- 奥義の 1 回目の吸収はダメージ 0 の付与で、sim はダメージ 0 の命中のイベントを出さない（`CombatSystem` の `amount > 0`）ので、命中の音（斬撃）は鳴らない。
- 実機（iPhone のスピーカー）での聞こえ方は未確認。
