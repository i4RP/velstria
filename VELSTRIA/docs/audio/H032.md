# H032 ディアス（MLBB: ディロス）のスキルの音

作り方: `python tools/audio/make_sounds.py H032`（`tools/audio/heroes/h032.py`）。素材はすべて Sonniss GDC Game Audio Bundle の
実際の録音（重い刃・斧の振りと打撃、刃と鎧のぶつかり、肉を斬る・貫く音、厚い鉄板の低いうなり、遠い雷の地鳴り）。
電子音・合成の音は使っていない。どの素材集を使ったかは [SOURCES.md](SOURCES.md)（自動生成）。

## なぜこの材質か

MLBB のディロスは奈落の力を宿した両腕の刃（鉤爪のような斧刃）で斬り込む戦士（演出は [docs/vfx/H032.md](../vfx/H032.md)）。
- 刃: 光る魔法の音ではなく、**重い金属の刃の振り（風切りと擦れ）**と、**斧と鎖を打ち合わせた重い金属の打撃**（Soundopolis の Collins Axe + Chains）。
- 命中: 刃が肉と鎧を斬る音（ゴアの録音・両手斧の肉への打撃・盾の金属）と体の砕け。
- 闇: 「重い衝撃と低音のうねり」を、**厚い鉄板の低いうなり**（Kopeikin の Black Metal。金属が低く唸る本物の録音）と
  **遠い雷の深い地鳴り**で作った。シンセの低音は使っていない。

命中の音は同じスキルで 0.1 秒に 1 回なので、+0.15 と +0.217 の 2・3 撃目は 2 撃目までが鳴る。

## 確かめたこと・まだのこと

- 4 帯域の 0.1 秒ごとの大きさで、輪（0.26・0.46・0.66 秒）・放つ時刻（0.76 秒）・命中（0 秒）に山が来ること、山が -1 dBFS を越えないこと、
  奥義の溜めが放つ前にふくらむことを確かめた。命中は低音と体の帯が金属より大きい（ロームの MLBB の打撃と同じ並び）。
- MLBB のディロスの効果音だけの録画はまだ無い。音量はロームの測定の物差しで、帯域の比べはしていない。
- 強化（アビス）の S1・S2 の音は通常と同じ（発動の時に強化か分からない）。
- 円撃: 4 帯域の 20 ms ごとの大きさで、払いの最大が 0.013 秒（命中と同時）に来て、低音の尾が最大より 8 dB 以上小さいことを確かめた。
  円撃の払いと命中の音を重ねた聞こえ方は未確認。
- `PM_BB_DESIGNED_CINEMATIC_CHOPS`（名前に DESIGNED）と NoizBoy - Hong Kong Action Kit の回る風は、素材集の側で加工済みの効果音
  （中身が録音だけかは素材集の説明で確かめていない）。
- 実機（iPhone のスピーカー）での聞こえ方は未確認。
