# 音（BGM・効果音）

- 仕組み: `App/Services/AudioService.swift`（AVAudioEngine）。音のファイル（`App/Services/AudioFiles.swift` の対応表、
  `App/Resources/Audio`）がある音はファイルで、無い・読めない音は `AudioLibrary.swift` の合成で鳴らす。
  - 効果音: 44.1 kHz モノラル 16 bit の `.caf`。起動時の効果音の合成と同じ裏の作業でバッファへ読む（プレイ中にファイルを読まない）。
  - BGM: 44.1 kHz ステレオ AAC の `.m4a`。`AVAudioFile` から流し読み（全部をメモリに展開しない）。読み終わりで頭から予約し直してループ、
    切替はクロスフェード。曲を始めるたびに増やす番号（`musicGeneration`）で、切り替えた後の古い曲の予約し直しを止める。
  - `AVAudioSession` は今までどおり `.ambient`（消音スイッチに従い、他のアプリの音と混ざる）。音量の設定（BGM・効果音・ボイス、
    既定はどちらも 0）と HUD の一時消音もそのまま。
- 素材: `tools/audio/build_audio.py` が CC0 の素材（Kenney の素材集・OpenGameArt の CC0 の曲）を `tools/audio/.cache` に落とし、
  切り出し・重ね・音程・音量・残響・形式の変換をして書き出す（素材の原本はリポジトリに入れない）。出典・ライセンス・URL は
  [SOURCES.md](SOURCES.md)（自動生成）とアプリ内の「クレジット > 音楽・効果音」（`CreditsCatalog.audio`。`AudioFilesTests` が一致を確かめる）。
- 使ってよい素材: CC0（Kenney の Interface Sounds など、OpenGameArt の CC0 の曲、Freesound の CC0）。Sonniss の GDC バンドルは
  重ね・切り出しなど加工した完成品だけ置く（原本・素材集の形では置かない）。MLBB の音は使わない（画面収録は参照だけ）。

## スキルの音（H025〜H034。2026-10-18 第 2 段）

- ファイル: スキル 1 つにつき `skill_<ヒーロー>_<s1|s2|ult>_cast.caf`（発動）と `..._hit.caf`（命中）、再使用の段は
  `..._r<段>_cast.caf`（H029 S2・H032 S2・H033 奥義）。作り方は `tools/audio/skill_sounds.py`（重ねと時刻の表）。
- 発動の音は、溜め → 振り → 決まった時刻の着弾 → 余韻を 1 つのファイルの中で、演出の `at:` と sim の時刻の定数
  （`FX_H0xx.swift` の Tune の写し。例: ボルグの奥義の崩落 1.0 秒・S1 の 3 波 0.25 / 0.58 / 0.92 秒、ゴルムの S2 の叩きつけ 0.27 秒、
  エウリアの奥義の落雷 0.45 秒と外側 +0.14 秒、ライナの奥義のビーム 0.55 秒）に合わせて並べた。発動のイベント（skillCast）で鳴らすので、
  演出（次の描画のフレーム）とは 1 フレーム以内でそろう。弾・範囲の着弾は命中の音（damage）で鳴る。
- 鳴らし方（`BattleAudioDirector`）: 発動は今までの汎用の発動の音と同じ音量・同じ間引き（ほかの人のスキルは 0.18 秒に 1 つ、
  聞こえる距離で弱める）で、そのヒーローの音があれば汎用の音の代わりに鳴らす。命中は自分（観戦者は追従中のユニット）が撃った・受けた
  命中 0.8、ほかは距離で 0.5 まで（`skillHitGain`）。同じスキルの命中は 0.1 秒に 1 回。
- 読み込み: 試合の始め（`BattleAudioDirector.start`）に、試合に出るヒーローの分だけ裏で読む（`AudioService.preloadSkillSounds`）。
  試合の終わりに捨てる。読み終わる前に撃ったスキルは汎用の発動の音。プレイ中にファイルを読まない。
- 素材: Kenney の Impact Sounds・RPG Audio・Sci-Fi Sounds・Digital Audio・Interface Sounds（CC0）と、作った風切り音・溜めの雑音・電気の
  ぱちぱち。長い素材の尾は発動 2.5 秒（奥義 3.5 秒）・命中 0.8 秒で切る。
