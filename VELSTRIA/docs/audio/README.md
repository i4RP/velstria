# 音（BGM・効果音）

**2026-10-20 から効果音はすべて実音の録音**（合成の効果音 SFXSynth と、Kenney の電子音・SF の音は外した。ファイルが無い効果音は鳴らさない）。
作り方は `python tools/audio/make_sounds.py <名前…>`（`sets/weapons.py` 武器ごとの通常攻撃の組・`sets/common.py` 戦闘の共通の音・
`sets/ui.py` 試合の外の画面の音・`sets/legacy.py` 旧 24 体のスキル・`heroes/h0xx.py` H025〜H034 のスキル）。表は [WEAPONS.md](WEAPONS.md)・
[LEGACY.md](LEGACY.md)・ヒーローごとの `H0xx.md`、どの録音を使ったかは [SOURCES.md](SOURCES.md)。
2026-10-27 にホーム・バトルのメインテーマを廃止し、ホーム専用の音源 3 曲も削除した。効果音・ボイス、ロビー・ドラフト・ロード・結果画面の BGM は継続する。
以下は 2026-10-18 までの記録（合成の扱いの記述は古い）。

- 仕組み: `App/Services/AudioService.swift`（AVAudioEngine）。音のファイル（`App/Services/AudioFiles.swift` の対応表、
  `App/Resources/Audio`）がある音はファイルで、無い・読めない音は `AudioLibrary.swift` の合成で鳴らす。
  - 効果音: 44.1 kHz モノラル 16 bit の `.caf`。起動時の効果音の合成と同じ裏の作業でバッファへ読む（プレイ中にファイルを読まない）。
  - BGM: 44.1 kHz ステレオ AAC の `.m4a`。`AVAudioFile` から流し読み（全部をメモリに展開しない）。読み終わりで頭から予約し直してループ、
    切替はクロスフェード。曲を始めるたびに増やす番号（`musicGeneration`）で、切り替えた後の古い曲の予約し直しを止める。
  - `AVAudioSession` は今までどおり `.ambient`（消音スイッチに従い、他のアプリの音と混ざる）。音量の設定（BGM・効果音・ボイス、
    既定は 2026-10-21 から効果音 70%・BGM 50%。10-05〜10-20 は 0）と HUD の一時消音もそのまま。
- 素材: `tools/audio/build_audio.py` が CC0 の素材（Kenney の素材集・OpenGameArt の CC0 の曲）を `tools/audio/.cache` に落とし、
  切り出し・重ね・音程・音量・残響・形式の変換をして書き出す（素材の原本はリポジトリに入れない）。出典・ライセンス・URL は
  [SOURCES.md](SOURCES.md)（自動生成）とアプリ内の「クレジット > 音楽・効果音」（`CreditsCatalog.audio`。`AudioFilesTests` が一致を確かめる）。
- 使ってよい素材: CC0（Kenney の Interface Sounds など、OpenGameArt の CC0 の曲、Freesound の CC0）。Sonniss の GDC バンドルは
  重ね・切り出しなど加工した完成品だけ置く（原本・素材集の形では置かない）。MLBB の音は使わない（画面収録は参照だけ）。

## スキルの音（H025〜H034。2026-10-18 第 2 段）

- ファイル: スキル 1 つにつき `skill_<ヒーロー>_<s1|s2|ult>_cast.caf`（発動）と `..._hit.caf`（命中）、再使用の段は
  `..._r<段>_cast.caf`（H029 S2・H032 S2・H033 奥義）。作り方は `tools/audio/skill_sounds.py`（重ねと時刻の表）。
- 発動の音は、溜め → 振り → 決まった時刻の着弾 → 余韻を 1 つのファイルの中で、演出の `at:` と sim の時刻の定数
  （`FX_H0xx.swift` の Tune の写し。例: ボルグの奥義の崩落 1.0 秒・S1 の 3 波 0.25 / 0.58 / 0.92 秒、ゴルムの S2 の叩きつけ 0.27 秒、
  エウリアの奥義の落雷 0.45 秒と外側 +0.14 秒、ライナの奥義のビーム 0.55 秒）に合わせて並べた。発動のイベント（skillCast）で鳴らすので、
  演出（次の描画のフレーム）とは 1 フレーム以内でそろう。弾・範囲の着弾は命中の音（damage）で鳴る。
- 鳴らし方（`BattleAudioDirector`）: 発動は今までの汎用の発動の音と同じ音量・同じ間引き（ほかの人のスキルは 0.18 秒に 1 つ、
  聞こえる距離で弱める）で、そのヒーローの音があれば汎用の音の代わりに鳴らす。命中は自分（観戦者は追従中のユニット）が撃った・受けた
  命中 0.8、ほかは距離で 0.5 まで（`skillHitGain`）。同じスキルの命中は 0.1 秒に 1 回。
- 読み込み: 試合の始め（`BattleAudioDirector.start`）に、試合に出るヒーローの分だけ裏で読む（`AudioService.preloadSkillSounds`）。
  試合の終わりに捨てる。読み終わる前に撃ったスキルは汎用の発動の音。プレイ中にファイルを読まない。
- 素材: Kenney の Impact Sounds・RPG Audio・Sci-Fi Sounds・Digital Audio・Interface Sounds（CC0）と、作った風切り音・溜めの雑音・電気の
  ぱちぱち。長い素材の尾は発動 2.5 秒（奥義 3.5 秒）・命中 0.8 秒で切る。

## ヒーロー固有の音 v2（ローム: H029 ボルグ・H034 ゴルム。2026-10-18）

レーンごとに仕上げる（ローム → ゴールド → ミッド → EXP → ジャングル）。仕上げたヒーローは `tools/audio/make_sounds.py（heroes/h0xx.py）` の音に置き換わる。
v1（`skill_sounds.py`）のヒーローはそのまま。

- 作り方: `python tools/audio/make_sounds.py（heroes/h0xx.py） H029 H034`。素材は Sonniss GDC Game Audio Bundle の録音（`tools/audio/sonniss_fetch.py` が
  archive.org の写しから使う素材集だけを `.cache/sonniss` へ落とす）を、材質ごとに 3〜5 層（溜め・振り/発射・命中の芯・材質の余韻・低音）
  に重ねる。打撃の素材は立ち上がり（振り → 着弾の素材は最大）を置いた時刻に揃える（`hit=True` / `hit="peak"`）。
  48 kHz モノラル、種類ごとの音量（LUFS）は MLBB の測定の値（`target`）に揃え、山は打撃の立ち上がりだけ抑える（-1 dBFS、6 dB まで）。
- 頭の無音は切らない: 0 秒 = 鳴らす時刻（発動・命中・攻撃の命中）。前は書き出しで頭の無音を切っていて、溜めから始まる音の着弾が
  sim・演出より早く鳴っていた（v1 の 8 個で 23〜200 ms。v1 も同じ書き出しを直した）。
- ファイル: 発動 `skill_<ヒーロー>_<s1|s2|ult>[_r<段>]_cast`、命中・通常攻撃・通常攻撃の命中は揺らぎ（`_1`〜`_4`。鳴らすたびに順に替える）
  `skill_<ヒーロー>_<スロット>_hit_<n>`・`skill_<ヒーロー>_atk_<n>`・`skill_<ヒーロー>_atkhit_<n>`、パッシブ `skill_<ヒーロー>_passive`。
  通常攻撃の音は近接の命中（`attackReleased`）で鳴る（着弾が 0 秒。振りの音は 0.04 秒前だけ）。
- 鳴らし方（`AudioService` のスキルの音の組）: 48 kHz の 24 本（今までの効果音の 8 本とは別）。左右の定位（聞き手からの横の距離、
  9 m で端・最大 ±0.85）、距離で弱める（今までと同じ `hearingRadius`）。奥義の発動では BGM・効果音・ほかのスキルの音を 1.4 秒だけ下げる。
  パッシブの音は演出が 3 秒止んでいた時だけ（毎秒たまるゴルムの闘気は、たまり始めの 1 回）。
- MLBB との比べ方: 効果音だけの画面収録（BGM 0・ボイス 0・効果音 100、手元だけ。リポジトリに入れない）の区間を、4 つの帯域
  （低音 30〜120 Hz・体 120〜600・金属 600〜3000・擦れ 3000〜12000）の 0.1 秒ごとの大きさと長さ・LUFS で測り、自作の音
  （発動と命中を sim の時刻に重ねたもの）と並べて詰める。結果は [MLBB_H029.md](MLBB_H029.md)・[MLBB_H034.md](MLBB_H034.md)。
