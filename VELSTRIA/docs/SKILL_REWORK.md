# スキル刷新（参照ヒーロー 12 体 → 既存キャラへの割り当て）

2026-10-07 方針決定。名前・アイコン・見た目（メッシュ）は今のまま。**スキルの効果・挙動・アニメーション・エフェクトだけ**を、
参照ヒーローのキットに合わせて作り直す。

## スキル枠は「パッシブ + スキル 2 つ + ULT」の 4 枠（全 24 体）

- `SkillSlot` は passive / skill1 / skill2 / ultimate。Skill3 は廃止（マスター・シミュレーション・HUD・SkillFX・テストから除去済み）。
- 参照ヒーローの S1 → skill1、S2 → skill2、ULT → ultimate。参照が 3 スキルなのでそのまま収まる。
- 例外は Fredrinn（ULT が 2 つ）: ultimate は 1 つにまとめ、**コンボポイントの数で分岐**する
  （コンボ 1 以上 = Energy Eruption、コンボ 3 = Appraiser's Wrath。どちらも発動時にポイントを消費）。
- 旧 Skill3 の汎用アーキタイプ（`groundAoE` / `healZone` / `selfAoE`）は枠としては無くなったが、実装は残す
  （ヒーロー固有スキルの部品として使う）。
- 経験値: ランクは基本スキル最大 4 ×2 + ULT 最大 3 = 11 ポイントを使い切る（Lv12 以降の余りポイントは未使用のまま）。
- HUD: 必殺技ボタンを旧 Skill3 の位置（攻撃ボタンの左）へ寄せ、ボタンは 3 つ（S1・S2・ULT）。

## 実装の進め方（次の段階）

1. ヒーロー固有スキルの層を sim に足す（`SkillCatalog` のスロット × ロール既定を、ヒーロー × スロットで上書きできるようにする）。
   必要な部品: 再使用（recast）の窓、強化の窓（Julian の 2 回 → 3 回目強化、Paquito の 3 回ごと）、形態（Sora）、
   スタック（Karrie の Mark、Fredrinn のコンボ、Gloo の Sticky）、残留物（Gloo の Goo、Julian の鎌）、
   引き寄せ・持ち上げ・投擲（Zhuxin、Kimmy）、全マップ視界 / 回復（Yi、Floryn）。
2. 12 体を 1 体ずつ、sim → SkillFX（演出・詠唱モーション）→ テストの順に置き換える。
3. 数値は参照のレンジを `Balance` の倍率に合わせて丸める（1v1 の TTK 目標は `SkillBalanceTests`）。
