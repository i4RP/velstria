# vfx_sprites

RealityKit のパーティクル（`ParticleEmitterComponent.ParticleEmitter.imageSequence`）で再生するフリップブックを
Python で手続き的に生成する。煙・炎・電撃・衝撃波・斬撃・氷・きらめき・闇の煙・地割れ・命中の火花の 12 種類。
絵はすべてこのスクリプトの手続き（ノイズ・図形）で作ったもので、他のゲームの素材は使っていない。

- 生成: `gen_sheets.py`（このフォルダ）
- PNG: `App/Resources/FX/Sheets/<name>.png`
- 一覧: `manifest.json`（このフォルダ）。`App/Resources` 以下はアプリのバンドル直下へ平らに入るので、
  `manifest.json` のような汎用の名前は PNG の横に置かない。

## 形式

- PNG・RGBA 8 bit・512×512。128×128 のコマが 4×4 に並ぶ。左上から行優先（0 = 左上、3 = 右上、4 = 2 行目の左）。
- 単色: RGB は全面 255（白）。形はすべてアルファに持つ（0 = 透明）。色はエンジン側の tint で付ける。
  芯は 255 近く、外へやわらかく落ち、縁はノイズで崩す。
- 各コマの外周 2 px は完全に透明（隣のコマへにじまない。生成時に検査して、違えば止まる）。
- 決定的: 乱数の種は固定。PNG は Pillow の `optimize=True` でメタデータなし（IHDR / IDAT / IEND だけ）。
  同じ環境で 2 回回すと同じバイト列になる（下の環境で確認。ライブラリの版が変わると変わりうる）。
- 1 枚 350 KB 以下（今は約 26〜78 KB）。
- `once` は 1 回再生（最後のコマはほぼ空）、`loop` は 16 コマで継ぎ目なく回る。`suggestedFPS` は 16〜24。

`manifest.json` は名前順の配列で、各要素は
`{ name, file, rows: 4, columns: 4, frames: 16, frameSize: 128, mode: "once" | "loop", suggestedFPS, bytes, sha256 }`。

## 作り直す

```sh
python gen_sheets.py                                   # 全シート → ../../App/Resources/FX/Sheets、manifest.json → このフォルダ
python gen_sheets.py --only fire_burst --only hit_flash # 一部だけ（manifest は出力先にある PNG から作り直す）
python gen_sheets.py --preview "$TEMP/vfx_sprites_preview"   # 確認用の合成画像も書く
```

`--out DIR` で PNG の出力先、`--manifest PATH` で manifest の出力先を変えられる。
確認用の画像（`<name>_preview.png`）はリポジトリの外へ書く（コミットしない）。16 コマを草地色（#5a6a50）と
暗色（#1b1f24）の上に、炎は橙・電撃と氷は水色・ほかは金色で tint して並べる。地面に寝かせる 2 種
（`shock_ring` / `ground_crack`）は、斜め 45° から見た形（縦を cos45° に潰したもの）も並べる。

確認した環境: Windows 11・Python 3.12.10・numpy 2.5.4・Pillow 12.3.0・scipy 1.18.1・opencv 5.0.0。全 12 枚で約 35 秒。

## 作り方の要点

- ノイズは 3D の Perlin（numpy でベクトル化）。ループするシートは縦と時間の格子に周期を持たせ、t = 0 → 1 で
  ちょうど 1 周期進める（円周上で時間を取るのと同じく継ぎ目が出ない。`loop_fbm`）。t = 1 のコマが t = 0 と一致することを確認済み。
- 溶けて消える表現は `dissolve`: ノイズ（と縁からの距離）の場で、アルファの総量の残り率が `keep_curve` に沿うしきい値を
  分位点で決める。ノイズの値の分布によらず、消え方がコマごとに一定の速さになる。
- 線もの（電撃・ひび・煙の筋・火花）は 4 倍の超解像で太さが変わる折れ線を被覆率で描き、面積平均で縮める。
