# mlbb_video

MLBB の画面収録（iPhone の横画面の録画）から、スキルの幾何（射程・半径・形）と時間（遅れ・間隔・突進の速さ）を測る道具。
最初の例は Tigreal（H029 聖槌のボルグ。`docs/kits/Tigreal.md`「動画で測った値（2026-10-15）」）。ほかの 9 体も同じ手順で測れる。

**動画・コマ・切り出した画像はリポジトリに入れない**（公開リポジトリ。著作物）。出力は既定で一時フォルダ（`%TEMP%\mlbb_video_out`）に書く。
`.gitignore` で画像・JSON・動画を除いてある。

依存: Python 3.10+、`pip install numpy opencv-python-headless scipy`。ffmpeg（winget の Gyan.FFmpeg）。

## 撮り方（精度に効く順）

1. 訓練場で、**最初に止まったまま各スキルの照準を 1〜2 秒出す**（照準の円・扇がカメラの較正と形の計測になる）。
   円の照準が 2 つ以上あると遠近（q）が決まる。1 つだけでは決まらない。
2. **床（キャンプの石畳など平らで模様のある所）の上を、ジョイスティックを倒したまま 1 秒以上まっすぐ歩く**。縮尺はこの歩きで決める。
   岩・草・壁の近くは避ける（高い所の模様は地面より速く動いて見え、縮尺が 1 割ずれる）。移動速度に効く装備・エンブレムの天賦は外す。
3. 的（CPU）の近くで各スキルを撃つ。的の体力の数字が見えていればダメージの確認になる。
4. 撮った後は止まったまま 1 秒置く（止まったコマどうしで地面のずれを測る）。

## 手順

```
ffmpeg -i rec.mp4 -vf fps=30 %TEMP%\vid\f30\%04d.png      # コマ n の時刻 = (n - 1) / 30
python measure.py montage --frames F --box 0,0,1108,512 --scale 0.35 1 16 31 46 ...   # 何がいつ起きたかを見る
python measure.py diff --frames F 40 35 --gain 4           # 照準のあるコマ − 無いコマ（同じカメラ位置）で縁を見る
```

1. **照準の円**（`ring`）: 照準の無いコマ（`--ref`）と有るコマ（`--at`、数コマの中央値）の差から縁の画素を拾う。
   `--guess` は楕円の中心と半軸の見当、`--exclude` は自分の体・体力バー・ボタン・ジョイスティックの箱。
2. **カメラ**（`camera ult s2`）: 同心の円（どれもヒーローの足元が中心）から地面への写像 `u = u0 + x/(1+qz)`、`v = v0 − c z/(1+qz)` を当てはめる。
   出力の「q を固定したときの残差」が最小の所で鋭く立っていれば遠近がよく決まっている。`rect` で真上から見た図を作り、
   床の円（キャンプの模様など）が円に見えることも確かめる。
3. **縮尺**（`speed --floor x,z,r0,r1 --speed 2.6`）: 床の範囲（`--from` のコマでのヒーロー px。真上から見た図の列 − 700、650 − 行）の
   特徴点だけで 1 コマの地面の変位を測り、`s = 変位 × fps / 移動速度`（MLBB の 260 = 毎秒 2.6）。「全部の点」の値との差が
   高い所の点の偏り（Tigreal の動画では 6%）。
4. **距離**（`move a b --patch c,r,半幅 --guess=dx,dz`）: 止まったコマどうしの地面のずれ（突進・瞬歩の距離）。
   `--guess` は負の数を含むので `=` でつなぐ。突進の最中のコマは画面の揺れで写像が崩れるので、止まったコマだけで測る。
5. **形**（`shape` → `trapezoid`）: 照準の塗りの輪郭を地面（単位）へ戻し、左右・奥の辺を直線で当てはめる（辺はおおよその端点で選ぶ）。
   体力バーなどの UI に隠れた所は輪郭が欠けるので、照準の向きを変えた 2 つの場面で測って比べる。
6. **時間**（`bands`）: 爆発（暖色の光）が軸に沿った帯ごとに増えたコマ = 爆発の始まり。`--quantile` で爆発の足元の位置。
   照準が消えたコマ = 指を離したコマ（その直前が発動）。CC の表示（「スタン」など）と時間のバー、CD の数字の切り替わり（切り上げ表示）は
   `montage` で目で読む。

## Tigreal の動画（2026-10-15）での値

| 量 | 値 |
|---|---|
| カメラ | u0 = 556.6、v0 = 295.0、c = 0.7096、q = 7.6 × 10⁻⁴ / px（2 つの円で残差 0.36 px） |
| 縮尺 | 床の歩き 5.40 ヒーロー px / コマ → s = 62.3 px / 単位（全部の点では 5.75 = 6% 高い所の偏り） |
| 照準の円 | 奥義 173.1 px = 2.78、スキル2 346.4 px = 5.56、スキル2 の再使用 133.7 px = 2.15（単位） |

Velstria の距離は MLBB × 100（射程 1.8 → 180）。測った値もそのまま × 100 で入れる。
