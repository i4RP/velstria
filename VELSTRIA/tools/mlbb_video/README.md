# mlbb_video

MLBB の画面収録（iPhone の横画面の録画）から、スキルの幾何（射程・半径・形）と時間（遅れ・間隔・突進の速さ）を測る道具。
最初の例は Tigreal（H029 聖槌のボルグ。`docs/kits/Tigreal.md`「動画で測った値（2026-10-15）」）、次が Franco（H034 鎖鉤のゴルム。
`docs/kits/Franco.md`「動画で測った値（2026-10-16）」）、Aurora（H031 氷嵐のオーリア。`docs/kits/Aurora.md`「動画で測った値（2026-10-16）」）、
Dyrroth（H032 赤拳のディアス。`docs/kits/Dyrroth.md`「動画で測った値（2026-10-16）」）。ほかの 6 体も同じ手順で測れる。

**動画・コマ・切り出した画像はリポジトリに入れない**（公開リポジトリ。著作物）。出力は既定で一時フォルダ（`%TEMP%\mlbb_video_out`）に書く。
`.gitignore` で画像・JSON・動画を除いてある。

依存: Python 3.10+、`pip install numpy opencv-python-headless scipy`。ffmpeg（winget の Gyan.FFmpeg）。

## 撮り方（精度に効く順）

1. 訓練場で、**最初に止まったまま各スキルの照準を 1〜2 秒出す**（照準の円・扇がカメラの較正と形の計測になる）。
   円の照準が 2 つ以上あると遠近（q）が決まる。1 つだけでは決まらない。大きさの違う円（小さい円と画面からはみ出す大きな円）があるとよく決まる。
2. **床（キャンプの石畳など平らで模様のある所）の上を、ジョイスティックを倒したまま 1 秒以上まっすぐ歩く**。縮尺はこの歩きで決める。
   岩・草・壁の近くは避ける（高い所の模様は地面より速く動いて見え、縮尺が 1 割ずれる）。移動速度に効く装備・エンブレムの天賦は外す
   （外せないときは、試合中のステータス画面の移動速度を撮っておく。Franco の動画は歩きが 260 の 5% 速く、ズームと移動速度のどちらの差か決め切れなかった）。
   パッシブで移動速度が変わるヒーロー（Franco の 5 秒無被弾 +10% など）は、その状態でない時の歩きも撮る。
3. 的（CPU）の近くで各スキルを撃つ。的の体力の数字が見えていればダメージの確認になる。
4. 撮った後は止まったまま 1 秒置く（止まったコマどうしで地面のずれを測る）。

## 手順

```
ffmpeg -i rec.mp4 -vf fps=30 %TEMP%\vid\f30\%04d.png      # コマ n の時刻 = (n - 1) / 30
python measure.py montage --frames F --box 0,0,1108,512 --scale 0.35 1 16 31 46 ...   # 何がいつ起きたかを見る
python measure.py diff --frames F 40 35 --gain 4           # 照準のあるコマ − 無いコマ（同じカメラ位置）で縁を見る
```

1. **照準の円**（`ring`）: 照準の無いコマ（`--ref`）と有るコマ（`--at`、数コマの中央値）の差から縁の画素を拾う。
   `--guess` は楕円の中心と半軸の見当、`--exclude` は自分の体・体力バー・ボタン・ジョイスティックの箱。
2. **カメラ**（`camera ult s2`）: 同心の円（どれもヒーローの足元が中心）から地面への写像 `u = u0 + x/(1+qz)`、`v = v0 − c z/(1+qz)` を当てはめる。
   出力の「q を固定したときの残差」が最小の所で鋭く立っていれば遠近がよく決まっている。`rect` で真上から見た図を作り、
   床の円（キャンプの模様など）が円に見えることも確かめる。
3. **縮尺**（`speed --floor x,z,r0,r1 --speed 2.6`）: 床の範囲（`--from` のコマでのヒーロー px。真上から見た図の列 − 700、650 − 行）の
   特徴点だけで 1 コマの地面の変位を測り、`s = 変位 × fps / 移動速度`（MLBB の 260 = 毎秒 2.6）。「全部の点」の値との差が
   高い所の点の偏り（Tigreal の動画では 6%）。
4. **距離**（`move a b --patch c,r,半幅 --guess=dx,dz`）: 止まったコマどうしの地面のずれ（突進・瞬歩の距離）。
   `--guess` は負の数を含むので `=` でつなぐ。突進の最中のコマは画面の揺れで写像が崩れるので、止まったコマだけで測る。
5. **形**（`shape` → `trapezoid`）: 照準の塗りの輪郭を地面（単位）へ戻し、左右・奥の辺を直線で当てはめる（辺はおおよその端点で選ぶ）。
   体力バーなどの UI に隠れた所は輪郭が欠けるので、照準の向きを変えた 2 つの場面で測って比べる。
6. **時間**（`bands`）: 爆発（暖色の光）が軸に沿った帯ごとに増えたコマ = 爆発の始まり。`--quantile` で爆発の足元の位置。
   照準が消えたコマ = 指を離したコマ（その直前が発動）。CC の表示（「スタン」など）と時間のバー、CD の数字の切り替わり（切り上げ表示）は
   `montage` で目で読む。
7. **大きな照準の円**（`arc`）: 画面からはみ出す円（Franco の鉤の射程 8.2）は `ring` の楕円の当てはめが効かない。カメラを固定して、
   地面の放射ごとに縁の半径を拾う（`--skip` で照準の線の向き、`--exclude` で UI を除く）。結果は `ring_<name>.json` なので `camera` にも渡せる。
8. **線の照準**（`lines`）: 軸に直交する断面ごとに線（左右の縁・中央）の横の位置を出し、向き（ずれの傾き）と半幅を当てはめる。
9. **飛ぶもの**（`tip`）: 鉤・弾の頭を、発射前のコマとも前のコマとも違う画素の、手元からの直線に沿った最も先の点として追う。宙に浮いた物は
   地面へ戻すと奥へずれるので、画面の横の座標 u だけで地面の距離に直す（向き θ は `lines` で測る）。的の手前（`--smax`）までで当てはめる。
10. **相手の動き・CC**（`bar`）: 的の体力バー（バッジとバーの左端）のテンプレートを各コマで探す。バーの位置の跳び = 引き寄せ・突進の始まりと終わり。
    バーのすぐ上の白い線が CC の時間のバー（新しい CC で満タンに戻り、右端が一定の速さで縮む）。線は「CPU」「スタン」の文字と重なるので、
    数値は目安にして、切れ目は `montage`（またはバーを追って拡大した切り出し）で目で読む。
11. **床の見当**（`walk`）: 歩きの特徴点の変位の分布。最も遅い山が床（高い所は速い）。`speed --floor` の範囲を決める前に見る。
12. **歩きながらの照準の形**（`gshape`）: 照準の無いコマ（`--ref`）の地面を、照準のコマ（`--at`）までの床のずれ（1 コマずつの特徴点の変位の和）
    だけ動かして重ね、真上から見た図で差分を取る。止まったコマでも使える（ずれ 0）。輪郭は `shape` と同じ JSON（`trapezoid` に渡せる）、
    差分の強さの図は `gshape_<name>.npy`（列 = x + 700、行 = 650 − z、1 画素 = 1 ヒーロー px）。扇の辺・弧は npy の角度・半径の断面で拾う。
13. **地点の照準の円**（`pcircle`）: 中心が術者でない地面の円（Aurora の隕石の着弾点）。地面の円を画面へ写した円周の上の差分の強さが
    最大になる中心・半径を探す。UI に隠れた所は `--exclude` で除く。放射ごとの縁の半径も出す（ばらつきが小さければ円）。
14. **ヒーローの足元は場面ごとに少し動く**（Aurora の動画では体力バーが ±2 px 動いた。歩いた後のカメラの遅れ）。c・q は Tigreal のまま、
    場面ごとに照準の円か扇の要から u0, v0 を当てはめ直して cam.json に書く（体力バーの左端 + (68.7, 119.6) px が足元）。
15. **術者が中心の照準の円**（`cring`）: c・q を固定して足元 u0, v0 と半径だけを当てはめる（`--fixfoot` で半径だけ）。照準の無いコマ（`--ref`）が
    歩いている間のコマなら、床のずれだけ動かして照準のコマに重ねてから差分を取る。照準の線・帯の向きは `--skip a0:a1`（度）で除く。
16. **地面に描かれる輪**（`decal`）: 衝撃の輪（Dyrroth のスキル1）の色の画素を地面へ戻して円で当てはめる。撃ったコマ（`--cast`）からの床のずれを
    打ち消して、撃った位置の地面の座標で書く。輪は地面より浮いて描かれるので中心が画面の奥へ少しずれる（Dyrroth で 0.4）。半径と間隔はそのまま使える。
17. **床のずれの分布**（`gridmove`）: 止まったコマどうしの地面のずれを、真上から見た図の格子の小片ぜんぶで測る。最も多い山が床
    （`move` の小片を手で選ばなくてよい。突進・飛びかかりの距離）。
18. **ヒーローの状態**（レイジ・闘気など）は測ったコマごとに読んで値と並べて書き、状態をまたいで平均しない（Dyrroth のレイジの 2 つの区画は
    満ちると赤・満ちていないと灰。強化の条件 50% = 左の区画が赤）。
