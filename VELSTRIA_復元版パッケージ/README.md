# VELSTRIA（ヴェルストリア）- 星環の戦場 / 復元版開発仕様パッケージ

このZIPは、会話内スクリーンショットに写っていた納品物を、直前の仕様説明に合わせて再構成したものです。**元ファイルの完全なバイナリ復元ではありません**が、実装へ引き継げるようデータを再生成しています。

## 主要成果物
- docs/VELSTRIA_要件定義書_復元版.pdf - 164ページ固定版
- docs/VELSTRIA_要件定義書_復元版.docx - 編集用
- docs/VELSTRIA_ゲームコンテンツマスター_復元版.xlsx - 46シート
- data/json/velstria_master.json - 正本マスター
- data/json/ / data/csv/ - 分割データ
- meshy/ - Meshy用プロンプト
- schemas/ - JSON Schema
- tools/validate_master.py - 参照/件数の簡易静的検査
- tools/reexport_csv.py - JSONからCSVを再出力

## 復元した規模
- ヒーロー 24体
- スキル 120定義
- 対戦装備 72種

- 機能モジュール 44
- 機能要件 110
- 受入テスト 31
- 参考アプリ監査項目 92

## 方針
課金商品は競技上の戦闘力を増加させない設計です。Meshyは3D形状・キャラクターベース・演出用メッシュ生成に使い、粒子・発光・トレイル・当たり判定・タイミング・音はゲームエンジン側で実装します。

## 検査
ZIP生成前に tools/validate_master.py を実行しています。対戦バランス、端末性能、ネットワーク負荷、ストア審査、実課金は別途実機検証が必要です。
